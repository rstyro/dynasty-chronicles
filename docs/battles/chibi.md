# 赤壁之战

> **208年 ｜ 孙刘联军 vs 曹操 ｜ 一场大火烧出三国鼎立。**

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **时间** | 208年（建安十三年） |
| **交战方** | 孙刘联军 vs 曹操 |
| **联军统帅** | 周瑜、刘备 |
| **曹军统帅** | 曹操 |
| **兵力** | 联军约5万 vs 曹军约20余万（号称80万） |
| **结果** | 曹操大败，退回北方 |
| **影响** | 奠定三国鼎立格局 |

---

## 📖 战役背景

曹操统一北方后，率大军南下。荆州刘琮投降，刘备败退。曹操欲一举吞并江东。孙权在[诸葛亮](/figures/strategists/sanguo/shu/zhuge-liang)和鲁肃劝说下，决定联合刘备抗曹。

---

## ⚔️ 战役过程

1. **孙刘联合**：诸葛亮舌战群儒，孙权决心抗曹
2. **黄盖诈降**：黄盖献苦肉计与火攻之策
3. **火烧连环**：东南风起，黄盖纵火烧曹军连环战船
4. **曹操败退**：曹军大乱，曹操走华容道退回北方
