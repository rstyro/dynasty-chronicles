# 好水川之战

> **1041年 ｜ 西夏 vs 北宋 ｜ 李元昊设伏好水川，宋军万人埋骨陇山。**

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **时间** | 1041年二月 |
| **交战方** | 西夏 vs 北宋 |
| **夏军统帅** | 李元昊（西夏景宗） |
| **宋军统帅** | 任福（行营都部署） |
| **兵力** | 西夏军十余万 vs 宋军数万 |
| **决战地点** | 好水川（今宁夏隆德西北） |
| **结果** | 宋军全军覆没，任福战死 |
| **影响** | 西夏确立对宋战略优势，宋廷震动 |

---

## 📖 战役背景

1038年李元昊称帝建西夏，宋夏战争爆发。1040年三川口之战宋军大败，1041年元昊再次南犯渭州。宋将任福奉韩琦之命率军迎击，元昊佯败诱敌，宋军轻进追击，进入好水川谷地——一张针对宋军的大网已然张开。

---

## ⚔️ 战役过程

1. **佯败诱敌**：元昊以弱兵引诱宋军，沿途丢弃牛羊辎重，宋军贪功冒进，越追越深
2. **瓮中设伏**：宋军深入好水川谷地，元昊将十万伏兵布于谷口两侧山梁
3. **鸽哨发令**：夏军以悬置的泥盒为号，宋军开启泥盒，白鸽飞出，伏兵四起
4. **全军覆没**：宋军数万被围歼于谷中，任福力战而死，将校数十人阵亡

---

## 📜 历史意义

- **夏强宋弱**：好水川、三川口、定川寨三战连败，西夏确立军事优势，宋廷只得承认西夏地位
- **元昊之智**：此战是元昊军事谋略的巅峰，以逸待劳、诱敌深入堪称经典
- **庆历之痛**：宋军连败震动朝野，促发范仲淹"庆历新政"的改革呼声
