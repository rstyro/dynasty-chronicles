# 昆阳之战

> 23 ｜ 位面之子刘秀的封神之战——不足两万破四十二万。

---

## 📖 概述

王莽篡汉后天下大乱，绿林军拥立刘玄为帝（更始帝），王莽派大司空王邑、大司徒王寻率四十二万大军围困昆阳城。城内绿林军不足万人，刘秀率十三骑突围求援，带回数千援兵。决战之日天降陨石暴雨——"夜有流星坠营中，昼有云如坏山当营而陨"，王莽军大乱，刘秀率三千敢死队冲入敌阵斩杀主将王寻，四十二万大军全军覆没。昆阳之战直接决定了新朝的覆灭，刘秀一战成名。
