# 成皋之战

> **前204–前203 ｜ 楚 vs 汉 ｜ 荥阳成皋拉锯，楚汉由相持走向转折。**

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **时间** | 前204年4月—前203年8月（楚汉相持阶段） |
| **地点** | 荥阳、成皋一线（今河南荥阳、巩义一带） |
| **交战方** | 楚军（项羽）vs 汉军（刘邦） |
| **楚军统帅** | 项羽 |
| **汉军统帅** | 刘邦 |
| **关键转折** | 纪信诓楚、曹咎渡汜水中计、鸿沟之盟 |
| **结果** | 楚军粮尽议和，楚汉中分天下 |
| **影响** | 楚汉战略形势逆转，刘邦由守转攻 |

---

## 📖 战役背景

彭城之战后，刘邦收拾残兵退守荥阳，依托敖仓粮道稳住阵脚。[韩信](/figures/generals/qinhan/xihan/han-xin)奉命开辟北方战线，先后破魏、灭赵、降燕，从侧翼对楚形成包围。项羽则亲率主力在荥阳、成皋一线与刘邦对峙，意图一举击破汉军主力。

---

## ⚔️ 战役过程

1. **荥阳之围**：项羽围攻荥阳，刘邦请和遭拒。[陈平](/figures/strategists/qinhan/xihan/chen-ping)献离间计，项羽怀疑亚父[范增](/figures/strategists/qinhan/chu-han/fan-zeng)，范增愤而离去，途中病发而死
2. **纪信诓楚**：汉将[纪信](/figures/generals/qinhan/chu-han/ji-xin)诈称汉王出降，刘邦趁乱乔装脱逃。项羽识破后烧杀纪信
3. **成皋拉锯**：刘邦依辕生之策南出武关调动楚军，同时[彭越](/figures/generals/qinhan/chu-han/peng-yue)在楚后方连下十七城、断楚粮道
4. **曹咎中计**：项羽东击彭越，留大司马[曹咎](/figures/generals/qinhan/chu-han/cao-jiu)守成皋。刘邦派人辱骂五日，曹咎怒而渡汜水出战，半渡遭汉军截击，大败，曹咎与司马欣自刎
5. **广武对峙**：项羽回师与刘邦隔着广武涧对峙数月，欲烹刘太公，刘邦曰"分我一杯羹"；项羽伏弩射中刘邦胸口
6. **鸿沟之盟**：[韩信](/figures/generals/qinhan/xihan/han-xin)破齐灭楚援军（[龙且](/figures/generals/qinhan/chu-han/long-ju)战死），彭越再断楚粮道，楚军兵少食尽，被迫与汉议和——以鸿沟为界中分天下，项羽引兵东归

---

## 🗣️ 成语典故

- **分我一杯羹**：刘邦面对项羽烹父威胁的戏谑回应
- **纪信诓楚**：后世忠义之士的典范，纪信舍身救主
