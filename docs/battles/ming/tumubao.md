# 土木堡之变

> 1449 ｜ 皇帝被俘、五十万大军覆没——大明由盛转衰的转折点。

---

## 📖 概述

明英宗朱祁镇在太监王振怂恿下，仓促率五十万大军御驾亲征瓦剌。大军行至土木堡（今河北怀来），因指挥混乱、水源被切断，全军陷入绝境。瓦剌首领也先率骑兵围攻，明军大乱，五十万大军全军覆没，明英宗被俘，王振被杀。消息传回京城，朝野震动。于谦力排南迁之议，拥立明代宗朱祁钰，组织北京保卫战击退瓦剌。此事件标志着明朝从鼎盛走向衰落。

## 📜 历史影响

- 明朝精锐部队和文武重臣几乎损失殆尽
- 从此明朝从战略进攻转为战略防御
- 于谦北京保卫战成为中流砥柱
