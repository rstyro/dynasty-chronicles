# 参合陂之战

> **395年 ｜ 北魏 vs 后燕 ｜ 拓跋鲜卑的立国之战，慕容燕国的转折之败。**

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **时间** | 395年十一月 |
| **交战方** | 北魏 vs 后燕 |
| **魏军统帅** | 拓跋珪（北魏道武帝） |
| **燕军统帅** | 慕容宝（后燕太子） |
| **兵力** | 魏军数万 vs 燕军八万余 |

---

## 📖 战役背景

前秦灭亡后，慕容垂复国建后燕，雄踞河北；拓跋珪重建代国改称魏（北魏），雄踞塞北。395年，慕容垂为剪除后患，命太子慕容宝率八万余大军北伐北魏。拓跋珪避敌锋芒，率部西撤，诱敌深入。

---

## ⚔️ 战役过程

1. **避锐西迁**：拓跋珪见燕军势盛，率部落退至黄河以西，以逸待劳
2. **燕军疲惫**：慕容宝深入塞北，数月不得决战，师老兵疲；又闻慕容垂病重，急欲退兵
3. **夜袭参合陂**：拓跋珪率精骑连夜追击，于参合陂趁燕军无备发动突袭
4. **坑杀降卒**：燕军大乱，人马自相践踏，死者无数，降者四五万人被坑杀，慕容宝单骑逃归

---

## 📜 历史意义

- **北魏奠基**：此战是拓跋珪统一北方的决定性胜利，北魏自此崛起为北方最强势力
- **后燕衰落**：精锐尽丧，慕容垂次年抱病亲征，途中病逝，后燕走向分裂衰亡
- **历史转折**：参合陂之战后，北中国格局由"燕强魏弱"转为"魏强燕弱"，为北魏统一北方奠定基础
