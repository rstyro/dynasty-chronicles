# 薛仁贵

> 614–683 ｜ "将军三箭定天山，壮士长歌入汉关。"——白袍小将的传奇一生。

---

## 📖 生平

薛仁贵，名礼，字仁贵，绛州龙门人。出身贫寒，唐太宗征高句丽时应募从军。安市城之战中，薛仁贵身穿白袍、手持方天画戟冲入敌阵，所向披靡，被唐太宗在远处看见后惊呼"朕不喜得辽东，喜得卿也"。此后随军平定铁勒九姓，三箭射杀三名敌将，铁勒军大惊溃散，留下了"将军三箭定天山"的千古美谈。晚年征突厥，突厥人闻其名而溃散。
