# 田单

> 战国·齐 ｜ "兵以正合，以奇胜。善之者，出奇无穷。"——《史记·田单列传》太史公赞

## 📖 生平

田单（生卒年不详），妫姓，田氏，名单，战国后期齐国名将，受封安平君。齐湣王时仅为临淄市掾（市场小吏），前284年燕将乐毅伐齐，连下七十余城，齐国仅剩即墨、莒两城。即墨大夫战死后，众人推举田单为将军，坚守孤城。

田单在即墨整饬军纪、善待士卒，并亲操版插（筑城工具）与士卒分劳。燕惠王即位后，田单施反间计，使燕国以骑劫取代乐毅，燕军士气大挫。前279年，田单收城中牛千余头，披五彩龙纹之衣，束利刃于角，灌油脂于尾，夜半点燃牛尾，火牛直冲燕军大营，五千壮士随后掩杀，燕军大溃，骑劫被杀。田单乘胜追击，一举收复齐国七十余城，迎齐襄王于莒复位，受封安平君。

## 💡 历史评价

1. **出奇无穷**：太史公赞其"兵以正合，以奇胜。善之者，出奇无穷"
2. **复国功臣**：以一城之将光复齐国，堪称战争奇迹
3. **巧施反间**：反间计换掉乐毅，一举扭转战局
4. **武庙享祀**：后世列入武庙，配享千秋
