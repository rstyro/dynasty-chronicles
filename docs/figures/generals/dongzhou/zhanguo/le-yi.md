# 乐毅

> 战国·燕 ｜ "善作者不必善成，善始者不必善终。"——《报燕惠王书》

---

## 📖 生平

乐毅（生卒年不详），子姓，乐氏，名毅，中山国灵寿（今河北灵寿）人，战国后期燕国名将，魏将乐羊之后。初仕赵国，后闻燕昭王筑黄金台招贤纳士，弃赵奔燕，被拜为亚卿、上将军。

燕昭王励精图治二十八年，誓报齐国破燕之仇。前284年，乐毅佩赵国相印，率燕、赵、韩、魏、秦五国联军伐齐，济西之战大破齐军，齐湣王出逃被杀。此后五国退兵，乐毅独率燕军长驱直入，五年间连下齐国七十余城，尽收齐之重器珍宝运回燕国，齐国仅剩即墨、莒两城，几乎亡国。

燕惠王即位后，齐将田单施反间计，散布乐毅欲据齐称王的谣言。燕惠王信以为真，以骑劫取代乐毅。乐毅自知被猜忌，出奔赵国，受封望诸君，终老于赵。田单以火牛阵大破燕军后，燕惠王追悔，作书请乐毅归国。乐毅复《报燕惠王书》婉拒，情辞恳切，君臣虽不复相见，却始终以书信礼敬，传为千古佳话。

## 💡 历史评价

1. **五国统帅**：合纵伐齐，战国规模最大的军事行动之一
2. **旷世战功**：五年下齐七十余城，几乎灭齐
3. **善始善终**：出奔赵国仍受敬重，与燕惠王书信往来传为佳话
4. **武庙名将**：诸葛亮早年"自比管仲、乐毅"
