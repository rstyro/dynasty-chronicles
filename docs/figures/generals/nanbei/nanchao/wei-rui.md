# 韦睿

> 442–520 ｜ 南朝儒将之首——钟离之战大破北魏二十余万，梁武帝称其"吾之张良"。

---

## 📖 生平

韦睿，字怀文，京兆杜陵人，出身关中世家。南朝梁名将，体弱多病、不能骑马，却每战必乘板舆督战，用兵如神。506年北魏中山王元英率大军南攻，围攻钟离（今安徽凤阳），梁武帝命韦睿率军救援。韦睿率轻骑昼夜兼程，与曹景宗合兵，采用火攻与反攻结合的战术，大破北魏二十余万大军，梁军俘虏魏军五万余人，北魏元气大伤。史称"钟离之战"，是南朝对北魏最辉煌的胜利。韦睿治军严明，与士卒同甘共苦，身患重病仍亲临前线，被北魏人称为"韦虎"。晚年梁武帝北伐失利，韦睿忧愤成疾，520年病逝。
