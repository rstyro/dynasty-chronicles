# 应龙

> 传说时代 ｜ "应龙已杀蚩尤，又杀夸父，乃去南方处之，故南方多雨。"——《山海经·大荒北经》

---

## 📖 生平

应龙，上古传说中黄帝麾下第一大将，又为神兽之名——相传其生有双翼，能兴云布雨，是龙族中唯一长翼者。涿鹿之战中，应龙受黄帝之命蓄水布阵，大破蚩尤所请的风伯雨师，最终诛杀蚩尤，助黄帝一统中原。

除诛蚩尤外，应龙还曾斩杀巨人夸父。传说大禹治水时，应龙亦以尾画地，为江河指引水道，"禹尽力沟洫，导川夷岳，黄龙曳尾于前"。后世因之尊应龙为"战神之祖"，凡战阵、兵符多以应龙为象，是中华军事传说中最古老的战神形象之一。

## 💡 历史评价

1. **战神之祖**：中华传说中最古老的战神形象，与蚩尤并称"兵主"
2. **黄帝肱股**：涿鹿之战决胜的关键人物，奠定华夏族群的军事传说
3. **人神同构**：由神话神兽演化为"黄帝大将"的叙事，见诸《山海经》《史记》等
4. **气象之神**：兴云布雨、主水，后世祈雨亦常祀应龙
