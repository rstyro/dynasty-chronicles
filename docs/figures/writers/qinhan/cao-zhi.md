# 曹植

## 📖 生平概述

曹植，字子建，沛国谯（今安徽亳州）人，曹操之子、曹丕同母弟。少时聪颖，十岁余诵读诗论及辞赋数十万言，出言为论、下笔成章，深得曹操宠爱，几度欲立为太子。建安年间随军征战，邺下文人雅集，与父兄并称"三曹"，与孔融、王粲等"七子"同声相应，是建安文坛最耀眼的明星。

然而曹植任性而行、不自雕励，尝醉酒夜行司马门，失宠于曹操；其友丁仪、杨修相继见疏被诛，太子之位终归曹丕。220年曹丕代汉称帝后，曹植备受猜忌，屡遭贬爵徙封，名为王侯，实同囚徒，十一年中三度迁都，汲汲无欢。黄初四年入京朝会，与同受猜忌的曹彪生离死别，愤而成《赠白马王彪》。

相传曹丕尝令其七步中作诗，不成者行大法，植应声而咏："煮豆燃豆萁，豆在釜中泣。本是同根生，相煎何太急。"太和三年（229年）徙封东阿，潜心儒籍；太和六年封陈王，是年十一月病逝于陈，年四十一，谥曰"思"，后世称陈思王。

## 🏛️ 文学成就

- **《洛神赋》**：叙邂逅洛水宓妃、人神道隔而不得结合的故事，辞采华茂、情思缱绻，"翩若惊鸿，婉若游龙"传诵千古，为建安辞赋最高成就。
- **《白马篇》**：以"白马饰金羁，连翩西北驰"起笔，塑捐躯赴难的游侠儿形象，寄托自己戮力上国、流惠下民的壮志，是建安风骨的代表之作。
- **五言诗的成熟**：现存诗八十余首，五言居其大半，《赠白马王彪》《野田黄雀行》诸篇骨气奇高、词采华茂，完成了乐府民歌向文人诗的转变，钟嵘《诗品》列为上品，誉其"譬人伦之有周孔"。
- **建安风骨之杰**：前期昂扬慷慨，后期沉郁悲凉，人生境遇之大起大落成就其诗格之跌宕，后人推为"建安之杰"。

## 🗣️ 后世影响

谢灵运尝言："天下才有一石，曹子建独占八斗"，"才高八斗"自此成为称誉文才的成语。其诗赋上承汉乐府与《古诗十九首》，下启六朝文人五言诗与骈俪文风，杜甫自比"文章曹植波澜阔"，李白亦步武其风。《洛神赋》后世衍为丹青长卷、戏曲传奇，顾恺之《洛神赋图》尤为画史名迹。其诗歌艺术可参见[诗词](/culture/literature/poetry)专题，辞赋成就可参见[赋](/culture/literature/fu)专题。
