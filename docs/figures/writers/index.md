# ✍️ 文学家

> 绣口一吐就是半个盛唐——从屈原到鲁迅，三千年文脉的书写者们。

---

## 📋 分类说明

文学家板块按**时代**组织，体裁领域（诗/词/赋/散文/小说/戏曲）在总览表的"领域"列标注，与 [文学专题](/culture/literature/) 互为表里：本板块看人，专题页看文体流变。

目录结构与人物板块一致：时代 → 朝代子目录。民国以后的人物 era 用"民国"，归入"现代"侧边栏分组。
