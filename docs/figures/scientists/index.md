## 📋 分类说明

科学家板块按**时代**组织，学科领域（数学/天文/医药/工程/农学/物理等）在总览表的"领域"列标注，便于按学科浏览。

目录结构与人物板块一致：时代 → 朝代子目录（如 `scientists/qinhan/`、`scientists/ming/`）。1912 年后的人物使用 `民国` / `现代` era 值，归入"现代"侧边栏分组。
