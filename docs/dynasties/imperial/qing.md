# 清朝

> 1644年–1912年 ｜ 中国最后一个封建王朝，康乾盛世与百年屈辱。

---

## 📖 概述

清朝由满洲爱新觉罗氏建立，入主中原后开创了长达一百三十余年的康乾盛世。清朝奠定了现代中国的疆域版图。然而，"闭关锁国"导致错过了工业革命的快车，鸦片战争后中国陷入半殖民地半封建社会的苦难深渊，最终在辛亥革命的炮火中结束了两千余年的帝制时代。

从山海关一片石之战到溥仪退位，清朝二百六十八年经历了四个阶段：入关定鼎与平定三藩、康雍乾盛世（统一台湾、三征噶尔丹、平定准部回部，疆域达极盛一千三百万平方公里）、嘉道中衰与鸦片战争、同光中兴与最终覆亡。清朝的文字狱与闭关政策常被诟病，但对边疆的经略（盟旗制度、金瓶掣签、改土归流、新疆建省）塑造了现代中国多民族国家的版图基础。

## 🏛️ 文化科技

- **典籍**：《四库全书》纂修与文字狱并行，乾嘉考据学大兴
- **文学**：《红楼梦》《聊斋志异》达到古典小说巅峰，纳兰词动人心魄
- **学术**：顾炎武、黄宗羲、王夫之开启实学；戴震、钱大昕为考据巨擘
- **科技**：王锡阐、梅文鼎会通中西天文历算；詹天佑铁路、侯德榜制碱开近代之新
- **艺术**：扬州八怪、宫廷画与瓷器工艺（康雍乾三代御窑）登峰造极
