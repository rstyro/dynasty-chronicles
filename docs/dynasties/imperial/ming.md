# 明朝

> 1368年–1644年 ｜ "天子守国门，君王死社稷。"

---

## 📖 概述

明朝由明太祖朱元璋建立，是最后一个由汉人建立的大一统王朝。明朝前期的永乐盛世、郑和下西洋展现了强大的国力。明朝也是中国资本主义萌芽的时期，市民文化空前繁荣。崇祯帝煤山自缢，为明朝画上了悲壮的句号。

二百七十六年间，明朝经历了从洪武立制、永乐扩张到仁宣守成的上升期，也经历了土木堡之变、夺门之变的逆转与嘉靖倭患、万历三大征的消耗，最终在内忧外患与财政崩溃中落幕。明朝修长城、设九边，"天子守国门"的格局塑造了此后六百年的北京地位；一条鞭法、隆庆开关则让白银经济深度融入全球贸易。

## 🏛️ 文化科技

- **制度**：废除丞相，设内阁；厂卫制度贯穿始终
- **航海**：郑和下西洋，早于哥伦布87年
- **文学**：四大名著之三成形（《三国演义》《水浒传》《西游记》），"三言二拍"标志市民文学兴起
- **科技**：李时珍《本草纲目》、宋应星《天工开物》、徐光启《农政全书》并出，晚明科技总结时代
- **哲学**：王阳明心学盛行，泰州学派走向民间
- **书画**：吴门四家、董其昌与松江画派
