# 五代十国

> 907年–960年 ｜ "天子，兵强马壮者为之。"——武人专政的极致，黑暗中的黎明前夜。

---

## 📖 概述

唐朝灭亡后，中国进入又一次大分裂时期。中原地区五十四年间换了五个朝代、八姓十四帝——后梁、后唐、后晋、后汉、后周走马灯般更替，史称"五代"。南方和山西则并存着十个割据政权，史称"十国"。这一时期的特点是：武人专政、军阀混战、政权短命。但后周世宗柴荣的改革为宋朝统一奠定了基础，而南方诸国的相对稳定也为经济文化南移创造了条件。

## 🏛️ 历史意义

- **燕云十六州之祸**：石敬瑭割让燕云，中原失去北方屏障，影响此后四百年的边防格局
- **武人政治顶峰**：五代将"兵强马壮者为天子"演绎到极致，警示后世以文抑武
- **南方经济崛起**：十国相对安定，江南经济文化持续发展，为宋代经济重心南移完成奠定基础
- **后周改革遗产**：柴荣整顿军队、均定田赋、限制佛教，为赵匡胤统一天下铺平了道路

## 🔗 关键人物

- 朱温 — 后梁开国皇帝，残暴寡恩
- 李存勖 — 后唐庄宗，勇武善战，得天下后迅速腐化
- 石敬瑭 — 割让燕云十六州，"儿皇帝"
- 周世宗柴荣 — 五代第一明君，雄才大略英年早逝
- 李煜 — 南唐后主，"问君能有几多愁"
- 钱镠 — 吴越国王，保境安民，钱塘江海塘修筑者
