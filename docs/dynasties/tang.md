# 唐朝

> 618年–907年 ｜ 大唐盛世，万国来朝，中华文明的高光时刻。

---

## 📖 概述

唐朝是中国历史上最强盛、最开放的王朝之一，与阿拉伯帝国并称当时世界两大帝国。贞观之治、开元盛世被誉为封建社会的黄金时代。唐诗更是中国文化史上的巅峰。289年的大唐帝国留下了无数璀璨的文化遗产。

## 🏛️ 文化成就

- **文学**：唐诗五万余首，李白、杜甫、白居易等千古诗人
- **艺术**：唐三彩、敦煌壁画
- **制度**：三省六部制完善、科举制度成熟
- **外交**：日本遣唐使、玄奘西行
