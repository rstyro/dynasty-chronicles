# 清朝

> 1644年–1912年 ｜ 中国最后一个封建王朝，康乾盛世与百年屈辱。

---

## 📖 概述

清朝由满洲爱新觉罗氏建立，入主中原后开创了长达一百三十余年的康乾盛世。清朝奠定了现代中国的疆域版图。然而，"闭关锁国"导致错过了工业革命的快车，鸦片战争后中国陷入半殖民地半封建社会的苦难深渊，最终在辛亥革命的炮火中结束了两千余年的帝制时代。
