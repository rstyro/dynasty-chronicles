# 十六国

> 304年–439年 ｜ "五胡乱华"——北方大分裂与民族大融合的时代。

---

## 📖 概述

十六国时期是指西晋末年至北魏统一北方期间，主要由匈奴、鲜卑、羯、氐、羌五个少数民族（史称"五胡"）在中国北方建立的诸多政权。最早由匈奴人刘渊建立前赵（304年），最晚由匈奴人赫连勃勃的大夏（431年）灭亡，实际上不止十六国。北魏太武帝于439年统一北方，十六国时期结束。这也是中国历史上一次大规模的民族融合过程。

## 🏛️ 历史意义

- **民族大融合**：五胡入主中原，胡汉相互通婚融合，为隋唐统一多民族国家奠定基础
- **佛教兴盛**：鸠摩罗什译经长安，佛教在乱世中广泛传播
- **南方开发**：北人南迁推动江南经济文化发展
- **军事变革**：骑兵战术和重装骑兵得到空前发展
