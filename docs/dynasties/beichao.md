# 北朝

> 386年–581年 ｜ 从鲜卑拓跋到关陇集团——隋唐盛世的真正源头。

---

## 📖 概述

北朝是十六国之后在北方建立的北魏、东魏、西魏、北齐、北周五个政权的统称。北魏由鲜卑拓跋部建立，439年统一北方，结束了十六国分裂。孝文帝推行汉化改革，迁都洛阳。后分裂为东魏（→北齐）和西魏（→北周）。北周灭北齐统一北方，581年杨坚代周建隋，随后南下灭陈统一全国。北朝开创的均田制、府兵制、三省制等制度被隋唐继承，影响深远。

## 🏛️ 制度创举

- **均田制**：北魏首创，按人口分配土地，隋唐继承
- **府兵制**：西魏宇文泰创立兵农合一的军事制度，延续至唐
- **三省六部制雏形**：北周官制改革为隋唐三省制奠基
- **关陇集团**：西魏–北周形成的军事贵族集团，创造了隋唐盛世
- **汉化与反汉化**：孝文帝全盘汉化 vs 六镇鲜卑化的文化博弈
