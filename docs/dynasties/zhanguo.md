# 战国时期

> 前475年–前221年 ｜ "争地以战，杀人盈野；争城以战，杀人盈城。"

---

## 📖 概述

战国时期是中国历史上列国兼并最剧烈的时代。经过春秋时期的兼并，到战国初期形成齐、楚、燕、韩、赵、魏、秦七雄并立的格局。各国先后推行变法图强，合纵连横的外交与大规模战争交织。最终秦国凭借商鞅变法奠定的制度优势，逐一吞并六国，完成统一。与此同时，诸子百家争鸣，创造了中华思想史上最辉煌的篇章。

## 🏛️ 制度文化

- **变法浪潮**：魏国李悝变法、楚国吴起变法、秦国商鞅变法
- **百家争鸣**：儒、墨、道、法、兵、纵横等学派并立
- **铁器普及**：铁制农具和兵器全面取代青铜
- **郡县制萌芽**：各国在边境地区推行郡县管理
- **军事革命**：车战转向步兵和骑兵，大规模歼灭战出现
