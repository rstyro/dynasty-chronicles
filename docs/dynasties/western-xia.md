# 西夏

> 1038年–1227年 ｜ 雄踞西北的党项帝国，"三分天下居其一"。

---

## 📖 概述

西夏由党项族首领李元昊建立，定都兴庆府（今宁夏银川）。西夏地处丝绸之路要冲，与北宋、辽朝形成三国鼎立之势。西夏创造了独特的西夏文字，发展了发达的佛教文化和军事体系。西夏在与宋、辽、金的对抗中展现出强大的军事实力，多次大败宋军。1227年，成吉思汗在征伐西夏途中病逝，蒙古军攻灭西夏，屠城毁文，西夏文明几乎被抹去。

## 🏛️ 制度文化

- **西夏文字**：李元昊命野利仁荣创制，共约6000字，形似汉字而结构复杂
- **佛教兴盛**：大量翻译刊印西夏文佛经，黑水城遗址出土大量文献
- **军事制度**：全民皆兵，实行"正军"与"负赡"制度
- **番汉分治**：设蕃学和汉学，分别培养党项和汉人人才
- **丝绸之路**：控制河西走廊，收取商税，经济繁荣
