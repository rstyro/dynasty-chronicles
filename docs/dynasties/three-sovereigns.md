# 三皇五帝

> 传说时代–约前2070年 ｜ "自从盘古开天地，三皇五帝到如今。"

---

## 📖 概述

三皇五帝是中国上古传说中的圣王时代，介于神话与信史之间。"三皇"与"五帝"的具体人选有多种说法，但总体代表了中国远古文明从采集渔猎走向农耕定居、从部落走向联盟的关键阶段。黄帝被尊为"人文初祖"，尧舜禹的"禅让"传说成为后世儒家政治理想的原型。

---

## 👑 三皇（主要说法）

| 说法来源 | 三皇 |
|----------|------|
| 《尚书大传》 | 燧人、伏羲、神农 |
| 《春秋运斗枢》 | 伏羲、女娲、神农 |
| 《帝王世纪》 | 伏羲、神农、黄帝 |

### 燧人氏 — 钻木取火
教民用火，结束了"茹毛饮血"的原始生活，被尊为"火祖"。

### 伏羲氏 — 人文始祖
创八卦、制嫁娶、结网罟、造书契，中华文明的奠基者。

### 神农氏 — 农业医药
尝百草、创医药、教农耕，"神农尝百草"的故事流传至今。

## 👑 五帝（《史记》说法）

| 帝号 | 主要事迹 |
|------|----------|
| **黄帝** | 败炎帝、杀蚩尤，统一华夏部落，被尊为"人文初祖" |
| **颛顼** | 绝地天通，进行宗教改革，制定历法 |
| **帝喾** | 顺天之义，知民之急，仁而威，惠而信 |
| **尧** | 定历法、治洪水，晚年禅让于舜 |
| **舜** | 孝感动天，流放四凶，禅让于禹 |

## 🏛️ 文化意义

- **华夏认同**：黄帝被后世尊为华夏民族的共同祖先
- **禅让理想**："天下为公，选贤与能"成为儒家政治最高理想
- **文明奠基**：农业、文字、历法、医药等文明要素在此阶段萌发
- **考古佐证**：仰韶文化、龙山文化等考古发现与传说时代有一定对应
