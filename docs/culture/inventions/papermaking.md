# 📜 造纸术

> 一纸之隔，文明为之翻页——造纸术让思想不再是贵族的特权。

---

## 📖 发明背景与起源

- **书写材料演进**：甲骨 → 竹简木牍 → 缣帛 → 早期纸（西汉灞桥纸）。
  - 竹简木牍笨重，秦始皇每日批阅的简牍重达百斤，"汗牛充栋"正是其写照；
  - 缣帛轻便却昂贵，"绢贵简重"成为造纸的直接动因——人们需要一种既轻便又廉价的书写载体。
- **早期雏形**：西汉已有麻纸，如陕西西安出土的**灞桥纸**（约公元前 2 世纪）和甘肃天水**放马滩纸地图**，但纸质粗糙、厚薄不匀、产量极低，尚不能真正替代简帛。
- **蔡伦改良（东汉 105 年）**：东汉和帝时宦官蔡伦总结前人经验，用**树皮、麻头、破布、旧渔网**为原料造纸，造出的纸质地优良、成本低廉，人称"**蔡侯纸"**。
  - 其划时代意义在于：将造纸原料从单一的麻拓展到废旧材料，实现"变废为宝"，使纸的大规模廉价生产成为可能。

## ⚒️ 详细制造过程

传统手工造纸（以楮皮纸为例）大致工序如下：

- **选料**：取楮皮、桑皮等韧皮纤维，或麻、竹、稻草。树皮需剥去外层青皮，剔除节疤朽烂处，切段、捆扎、晾晒待用。
- **沤泡**：将原料浸入水中数日，再投入石灰水池或草木灰水中沤制，使纤维软化、胶质溶解，同时石灰的碱性可腐蚀残留的蜡质与杂质。
- **蒸煮**：将沤好的原料入锅高温蒸煮，进一步分离纤维、去除木素与色料。蒸煮后原料变软，轻捏即散为纤维状。
- **洗涤漂白**：用清水反复漂洗，去除碱液与杂质；可露天日晒，利用日光紫外线漂白纤维，使其洁白。
- **捣浆（打浆）**：将漂洗后的纤维放入石臼，以木杵舂捣成细碎纸浆，倒入水槽加水搅拌，使纤维均匀悬浮于水中。打浆程度决定成纸的匀度与强度。
- **抄纸**：手持竹帘（细竹丝编成，帘面筛纹即"帘纹"）斜插入浆水，前后左右晃动荡匀，使纤维交错铺展于帘面，提起滤水后形成湿纸页。
  - **关键控制**：帘架晃动须平稳均匀，浆水浓度适中，否则成纸厚薄不匀、出现破洞。
- **加纸药**：浆水中常加入**黄蜀葵、杨桃藤**等植物黏液（纸药），使纤维悬浮更久、抄纸更薄且不易粘帘，此乃古代造纸的"技术绝活"。
- **压榨**：湿纸页连同帘子覆压于木板上，层层叠加至数百张，再用杠杆或石压压去多余水分，使纸页紧实贴合。
- **晾晒/烘干**：揭下压实的纸页，贴于火墙（壁晾）或用烘纸炉烘干。至此，一张平整柔韧的纸张便告完成。

## 🌍 传播与影响

- **西传之路**：唐天宝年间怛罗斯之战（751 年）后，阿拉伯人俘获中国造纸工匠，在撒马尔罕建起纸坊，造纸术由此传入中亚，继而经巴格达、大马士革传至北非与伊比利亚半岛。
- **欧洲变革**：12 世纪造纸术传入欧洲，纸逐渐取代昂贵的羊皮纸，书籍价格骤降、抄本激增，为文艺复兴的思想传播与宗教改革运动铺平了道路。
- **世界影响**：造纸术与印刷术结合，使知识得以低成本复制与传播，被公认为人类文明史上最具革命性的发明之一。
