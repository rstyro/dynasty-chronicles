# ⚒ 制造工艺与冶金

> 百工之事，皆圣人之作——火与土、木与丝之间炼成的造物之力。

---

本专题聚焦中国古代的"制作工艺技术"而非艺术审美：从炉火中炼出的金属，从窑火中烧成的陶瓷，从草木中鞣出的皮革，从经纬中织出的布帛。每个小节为一个独立领域，为后续细化为独立子页面预留框架。

## 🔥 炼铁炼钢

- **生铁冶炼**：春秋晚期出现块炼铁，战国时期生铁冶铸成熟，比欧洲早约一千五百年。
- **铸铁柔化**：战国工匠通过退火处理使生铁脱碳变韧，制成可锻铸铁，广泛用于农具与兵器。
- **炒钢法**：汉代把生铁加热搅拌脱碳成钢，炼钢从"锻"走向"炼"，效率大增。
- **灌钢法**：南北朝綦毋怀文发明，以生铁水灌入熟铁渗碳成钢，是当时最先进的炼钢技术。
- **百炼钢**：反复折叠锻打去除杂质，是刀剑锻造工艺的核心。

## 🏺 青铜铸造

- **范铸法**：以陶范翻模浇铸，殷商时已达极高水平；司母戊鼎（后母戊鼎）重 832.84 千克，为现存最大的青铜器。
- **失蜡法**：以蜡制模、外敷陶范，熔蜡浇铜，可铸出复杂镂空器物，春秋战国渐趋成熟。
- **分铸与调音**：复杂器物分件铸造再合体；曾侯乙编钟以"一钟双音"展现铸造与调音技术的顶峰。

## 🍶 陶瓷烧制

- **演进主线**：新石器陶器 → 商代原始瓷 → 东汉成熟青瓷 → 唐代白瓷与三彩 → 宋代五大名窑 → 元代青花 → 明清景德镇。
- **窑炉技术**：龙窑依山而建、升温降温快；宋代出现匣钵装烧，可精确控制釉色与窑变。
- **釉与胎**：青瓷以铁元素呈色，白瓷以降低含铁量实现；景德镇的"瓷都"地位得益于高岭土资源与分工精细的窑业体系。

## 🧤 皮革鞣制

- 上古先民以烟熏、晾晒等法保存兽皮，后发展为浸渍、揉搓的软化处理。
- 植物鞣法以树皮、果实中的单宁浸制皮革，成品耐水耐用，用于甲胄、箭袋、马具与农具。
- 皮革与鞣制工艺是古代军备与游牧—农耕交流的重要技术纽带，历代官营工场皆设"皮作"。

## 🧵 纺织印染

- **缫丝织绸**：新石器晚期已能缫丝，良渚文化出土丝织物残片；汉代"丝绸之路"使丝绸成为世界性商品。
- **织机技术**：汉代提花机能织复杂花纹，三国马钧改进织机，蜀锦名扬天下。
- **印染工艺**：蜡缬（蜡染）、绞缬（扎染）、夹缬（夹版印花）"三缬"并立，染料以植物靛蓝、茜草、红花为主。
- **后世名产**：宋锦、云锦、缂丝，代表丝织技艺的顶峰。
