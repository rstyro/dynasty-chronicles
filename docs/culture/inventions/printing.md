# 🖨 印刷术

> 从石刻拓印到雕版印书，再到毕昇的泥活字——印刷术让知识第一次能够大规模、低成本地复制与传播。

---

## 📖 发明背景与起源

- **印章与碑拓的技术前奏**：印章多为反文阳刻，捺印即成正字，是最早的"印版"雏形；东汉以后碑刻盛行，人们用湿纸覆碑、捶打上墨拓印，碑拓实现了平面文字的批量复制，二者为雕版印刷提供了"反文阳刻"与"传拓"两大核心技术。
- **佛教传播的推动**：唐代佛教兴盛，寺院和信众需要大量复制佛经、佛像与咒语，手抄远不能满足需求，直接催生了雕版印刷。
- **现存最早印刷品**：咸通九年（868 年）王玠为双亲敬造《金刚经》，1900 年出土于敦煌藏经洞，全卷图文并茂，卷首有释迦牟尼说法图，刀法娴熟，证明当时雕版印刷已相当成熟。
- **唐代的普及**：中晚唐时期，民间已大量印售历书、佛经、诗集和字书，东川、扬州等地出现了专业的印书作坊。

## ⚒️ 雕版印刷制造过程

传统雕版印刷大体分四道工序：

1. **写样**：将文字按版式反写（镜像）于薄纸上，或正写后用油纸反覆，使字呈反形；再将写样覆于版面作为雕刻依据。若需插图，则由画工先勾白描画稿。
2. **雕刻**：选用梨木、枣木等木质细密坚硬的木材，锯成板料后刨平、打磨光滑；以浆糊将写样反贴于版面，待干后镌刻。刻工沿笔画用拳刀**剔**出字腔，再用平口刀**挖**去空白处，以弯凿**修**整边缘，阴刻使字面凸起为阳文反字，并保留墨线边框与栏线。
3. **刷印**：将印版固定于案上，先用棕刷蘸墨均匀涂刷版面；覆上纸张，再用干净的棕刷在纸背轻刷压拂，使墨色渗印于纸上；揭起晾干，即成单页。
4. **装订**：将印好的书页对折、按序**配页**，齐栏后压实，再经切边、打孔，用丝线或纸捻**线装**成册。装订为册叶装后，雕版印刷的书本形式基本定型。

## ⚒️ 活字印刷制造过程（毕昇）

宋仁宗庆历年间（1041—1048 年），平民毕昇首创泥活字。依沈括《梦溪笔谈》记载，工序如下：

1. **制字**："用胶泥刻字，薄如钱唇，每字为一印"——以胶泥制成字坯，刻出反文阳字，每字独立成一印。
2. **火烧**："火烧令坚"——将刻好的泥活字入火焙烧，使其坚硬如陶，便于长久使用。
3. **排版**："先设一铁版，其上以松脂、蜡和纸灰之类冒之。欲印，则以一铁范置铁版上，乃密布字印，满铁范为一版，持就火炀之，药稍镕，则以一平板按其面，则字平如砥"——铁版上敷松脂、蜡与纸灰作粘合药料，以铁框（铁范）围定版面，将活字按稿排满一框，放到火上烘烤使蜡熔化，再用平板压平字面。
4. **印刷与拆版**："若止印三二本，未为简易；若印数十百千本，则极为神速"——刷墨覆纸印完所需份数后，"火令药镕，以手拂之，其印自落，殊不沾污"，烤热使药料熔化，取下活字以备再用。
5. **常用字备字**：毕昇另备两块铁版交替使用（"更互用之"），并"每字皆有数印"，如"之""也"等常用字多备二十余印；生僻字则临时旋刻、用草火烧成，兼顾了速度与排版灵活性。

**优势**：活字可拆可排、循环使用，印量大时省工省料；但《梦溪笔谈》也指出其短处——若只印三五本，反不如雕版简便，故当时未广泛流行。

## 📚 后世发展

- **元代**：农学家王祯创制木活字，并发明转轮排字盘，以字就人、依韵检字，极大提高拣字效率，其《造活字印书法》是世界最早的活字印刷专著。
- **明清**：铜活字技术成熟，清康熙至雍正年间用铜活字排印《古今图书集成》，全书一万余卷，是中国历史上规模最大的活字印书工程。
- **影响**：印刷术使书籍价格骤降、产量激增，推动宋代书院与科举取士的兴盛，加速了文化的普及与知识的下沉。

## 🌍 传播与影响

- **东传与西传**：雕版印刷经丝绸之路与海路东传朝鲜、日本，西传中亚与西亚；活字印刷术亦随使节、商旅与宗教交流传往周边地区。
- **欧洲的印刷革命**：约 15 世纪中叶，德国人约翰内斯·古登堡改进活字印刷，以铅锡合金铸造活字、配以油性墨与螺旋压印机，使印刷效率远超手工抄录。
- **文明的分水岭**：书籍由此从少数精英的珍藏变为大众可及之物，知识传播速度呈指数级增长，直接为欧洲文艺复兴、宗教改革与近代科学革命铺平了道路，成为人类文明史的重要转折点。
