# 🧼 肥皂制作

> 古人讲究"沐浴而朝"，洗濯并非小事。早在两千年多前的《礼记》里，"沐稷而靧粱"——以谷物汁洗头、淘米水洗脸——已是士人的日常功课；而后世闺阁里的澡豆、市集上的肥皂荚，更是把"洗得干净"这门手艺磨成了学问。若你穿越回古代，身边的草木灰与一锅猪油，便是制出一块可用之皂的全部材料。本文就从烧灰开始，教你走完这条完整的制皂之路。

---

## 📖 清洁的智慧：古人如何洗涤

- **清洁的本质**：水本身洗不掉油脂，去污靠的是**表面活性剂**——一种一头亲水、一头亲油（疏水）的分子。它的疏水端抱住油污，亲水端被水拖走，油污便随水流而去。
- **古代洗涤物演进**：草木灰水（最早）→ 皂荚/皂角 → 澡豆（豆粉+香料）→ 碱皂 → 现代肥皂。可见"以灰去垢"是最古老、也最接近制皂的起点。
- **中国古人何时开始皂化**：宋代庄绰《鸡肋编》记载，浙人把皂荚捣烂与草木灰汁相和，制成"肥皂"；西方古罗马亦早有用羊脂与草木灰熬皂的先例（普林尼《自然史》有载）。东西方殊途，原理同一。
- **本文目标**：只用古代可得材料——草木灰提碱、动物油脂备脂——做出**一块真正能去污的皂**。全程四步：**制碱 → 备脂 → 皂化 → 成型**，一步都不能省。

## 🔥 制碱：草木灰提碱（最关键的原料）

> 制皂成败七分在碱。没有浓淡合适的碱液，后面的皂化无从谈起。这一节是全篇的命门。

### 原理

- 草木灰中含有大量**碳酸钾（钾碱，K₂CO₃）**，溶水后生成强碱性的碳酸氢钾溶液，就是古人所称的"**灰汁**"。灰汁的碱性足以与油脂发生皂化，是最易得的天然碱源。

### 取材：哪种灰碱最高

- **首选禾本科**：烧稻草、麦秆、蒿草、葵杆得到的灰，含碱量最高，是古代淋灰取碱的上品。
- **次选木灰**：松枝、桑枝、柞木等硬杂木灰亦可，但含碱略低。
- **禁忌**：煤灰、被污染的灰、混入泥土的灰皆不可用——泥土中的钙、铁会与碱结合，白白浪费。

### 步骤

1. **烧灰**：把草秆充分燃烧至**灰白发轻**，忌夹生黑炭（黑炭是不完全燃烧，含碱极低）。烧出的灰收集、晾干、过筛去粗渣。
2. **淋灰取碱**：取一漏盆或竹筐，底部垫草帘、铺灰压实；把清水**缓慢反复浇淋**在灰面上，滤下的水即为"**灰汁**"——颜色浅黄澄清、尝之微涩、手搓滑腻。
3. **提浓碱液**：若嫌碱淡，有两种办法——①把灰汁入锅**小火慢熬浓缩**；②拌入少许**石灰水（氢氧化钙）**，钾盐转化为强碱性的氢氧化钾，碱力大增，皂化更快更彻底。**"灰汁+石灰"是古代提速皂化的关键改良**，后世硬皂多用此法。

### 判断经验（碱液够不够浓）

- **手感法**：手指蘸灰汁，两指相搓**滑腻如皂**，即为可用；淡得如水，则需重新浓缩。
- **浮蛋法**：新鲜鸡蛋投入碱液，若**能半浮于液面**（比重大于水），浓度便足够。
- **乳化法**：滴两滴油脂入碱液，振荡后**能混浊乳化不分层**，说明碱力足可皂化。

### 安全注意

- 碱液**强腐蚀**，制作全程**避免接触皮肤与眼睛**，最好备一盆醋水以应急中和。陶瓦容器盛碱，忌用铜铁锅熬浓碱（会腐蚀器物）。

## 🧈 备脂：动物油脂的选用与处理

> 碱有了，还缺"油"。动物脂肪是古人最易得的油脂来源，处理得当，出油率高、皂质细腻。

### 原理与选用

- 油脂的本质是**脂肪酸甘油酯**，它是皂化反应的另一半原料。不同油脂皂化后软硬不同：
  - **猪油**：最常用，皂质柔白细腻，冷天手洗俱宜。
  - **牛油/羊油**：皂体偏硬、耐用，适合做洗衣皂、去垢皂。
  - **鸡油**：皂体偏软，可少量混用增加滋润。
- **植物油脂（可作补充）**：菜籽油、茶油、桐油——后二者古人不陌生（《本草纲目》均载），皂化成的皂偏软，宜与动物油掺配。

### 步骤（熟油）

1. **切块**：肥肉、板油切小方块，去净瘦肉筋膜（带瘦则油易焦腥）。
2. **熬炼**：肉块入锅，加少许清水，**小火慢熬**，不断翻动。清水先让肥肉受热均匀，水干后油渐出，改小火继续煨。
3. **过滤**：熬至油渣金黄酥脆、不再出油即停火；用纱布/细筛趁热滤出**澄清油液**，装罐放凉待用。
4. **判断与火候**：油色**清亮、无焦糊味**为佳。**忌熬焦**——焦油色深味苦，皂色发暗还带腥焦气；油渣滤净，否则杂质会让皂长斑。

### 安全注意

- 熬油时**油锅不离人**，高温油星易烫伤；滤油要趁温热（油冷则凝，滤不干净），但不可滚沸时直接倒滤布（烫手、油易溅）。

## 🧪 皂化：油碱相遇（核心反应）

> 碱与油一相逢，便是本文的高潮——皂化反应。成败全看这一锅。

### 原理

- **皂化反应**：油脂（脂肪酸甘油酯）+ 碱 → **肥皂（脂肪酸盐）+ 甘油**。碱液中的氢氧根打断油脂的酯键，油分子分解，一头变成能亲水的"皂"（脂肪酸盐），另一头变成滋润保湿的甘油。古人不懂化学式，却用"画字能留痕"的经验精准地控制了它。

### 制作步骤（热煮法）

1. **配比**：油脂与浓碱液按**体积约 2:1** 混合（经验值）。**油多则皂软**（滋润但不耐用），**碱多则皂苛**（去污强但咬手伤肤）。宁可碱略欠，不可碱过头。
2. **加热混合**：油入锅**微热**（不烫手、约四十度上下），缓缓倒入碱液，**边倒边搅拌**，使油碱充分交融，此即古人所谓"**打发**"。
3. **熬皂**：转为**小火慢煮**，持续搅拌（方向一致、勿停），锅面渐起细密泡沫，皂液由浑变稠、由黄转白。
4. **判断皂熟**：用勺舀起皂液**缓缓倒回**，液面能"**画字能留痕**"（在皂液表面写画，纹理停留不即散），即皂化完成。
5. **冷却定型**：趁热倒入**木模/竹筒/瓦盆**（内壁可抹油防粘），放凉凝固。
6. **切块熟成**：凝固后脱模切块，置于阴凉通风处**阴干数日至数周**。这段"**熟成期**"里，残余游离碱与油脂继续缓慢反应，皂质更硬、更温和，用之才不伤皮肤。

### 判断经验（补充）

- **滴水法**：滴几滴皂液入冷水，若**凝成珠、不散开**，说明油碱已化合成皂；若入水即散，则皂化未足，继续熬煮。
- **过碱处理**：皂成后若搓洗"**咬手**"（过碱），可用**盐水浸泡**中和，或泡入**醋水（酸）** 里调一调，再晾干即缓和。

### 安全注意

- 碱液与热皂液**腐蚀性极强**，全程避开皮肤眼睛，锅铲专人专用，莫混入食具。熬皂时碱液遇热易飞溅，**手脸勿俯锅面**。

## 🧴 皂的再加工与使用

- **加香**：皂化将成时调入**桂花、檀香、丁香**等研成的细末（古人澡豆早有以香和皂的传统），皂成即带幽香。
- **加药**：加入**薄荷、艾叶、皂角粉**等有清洁药用之物，做成药皂，洗浴兼疗身。
- **皂荚与皂角直接用法**：天然清洁剂——皂荚泡水搓揉，泡沫丰富，可直接洗衣洗身，无须皂化。
- **澡豆的做法**：豆粉 + 皂荚粉 + 香料 + 少量碱，加水和匀捏成小丸，晾干即成。古人以此**每日洁面**，实为肥皂之前身。

## 📜 历史小考

- **《礼记·内则》**："沐稷而靧粱"——用谷物汤汁洗发、淘米水洁面，是最早见于典籍的洗涤方式。
- **晋代**已见"**澡豆**"记载，以豆粉和药为之。
- **唐·孙思邈《千金要方》**载有"洗面药""澡豆方"，配方细致，可见唐代清洁用品已相当讲究。
- **宋·庄绰《鸡肋编》**："浙中少皂荚，澡面浣衣皆用灰汁"；《梦粱录》记临安市场有"肥皂"售卖，宋人已把灰汁与皂荚制成商品皂。
- **明·李时珍《本草纲目》**载"肥皂荚"，详述其洗垢之功，也印证了草木灰与油脂合制之皂在民间的普及。
- **东西方制皂**：西方以羊脂+草木灰（古罗马），东方以猪油/皂荚+灰汁（宋代），原料略有别，皂化之理同一，殊途而同归。
