# 🧭 指南针

> 磁石磨针锋，则能指南——从战国司南到罗盘远航，人类从此有了全天候的方向。

---

## 📖 发明背景与起源

- **磁性认知**：天然磁石（磁铁矿）自古为中国人所认识，《吕氏春秋》即载"磁石召铁"；其吸铁之性被视为"慈石"（慈母引子）的象征，而指示南北的特性则催生了最早的方向仪。
- **司南记载**：战国文献中已见司南的雏形。《韩非子·有度》记"先王立司南以端朝夕"，言其正方位、定时间；《鬼谷子》亦称"郑人之取玉也，必载司南之车"，司南已成为辨方向的工具。
- **勺形结构**：司南以天然磁石琢成勺状，勺柄指南，置于光滑的"地盘"（铜质或漆木圆盘）上，盘面刻八方或二十四向。勺底圆滑、重心居勺腹，轻拨即旋，静后勺柄指北、勺口指南。
- **汉代式盘**：汉代占卜盛行"式盘"，由天盘与地盘组成，刻度细密。磁勺与式盘结合后，方向的分度更加精确，为后世罗盘的诞生奠定基础。
- **演进逻辑**：勺形司南体大笨重、需要平整底盘，不适于颠簸的舟车与随身携带；将磁性集中于细长铁针、以枢轴或悬丝支撑，便成为小型化、可动式的必然选择——这正是从司南走向指南针的内在动力。

## ⚒️ 详细制造过程

- **磁石采炼**：天然磁石多产于铁矿露头处，古人在采矿中挑选质地坚硬、磁性强的磁铁矿。判别之法为"吸铁验性"：以铁屑或细铁针试其吸引之力，凡能吸附铁针且吸引强者，方为可用之磁石。磁石需避火锻、防磕撞，以免高温与震动消磁。
- **人工磁化（关键）**：北宋沈括《梦溪笔谈》记载了两种磁化钢针的方法——
  - **摩擦法**："以磁石磨针锋，则能指南。"取细长钢针，以磁石一端沿针身单一方向反复摩擦数十遍，使针内磁畴整齐排列而成磁针。磨毕验之：将针平放水面，针尖与针尾即自动转向南北。
  - **缕悬法**：沈括详述"缕悬"之技——取新茧中抽出的单根蚕丝（"独茧缕"），以芥子大小的蜡珠缀于针腰处，将针悬于空中。因丝细无扭力、悬点正在重心，磁针可自由旋转以取南北，误差极小。沈括明言此法"最善"，胜于水面漂浮与指爪支托之扰。
  - **水浮法**：另以数根灯芯草（或细木片）托针，置针于水面使其漂浮，针随水旋而定向。此法人称"水罗盘"，是航海罗盘的主要形式。
- **罗盘制作**：将磁针与方位盘结合——
  - **方位盘**：圆盘分二十四向，即天干十字（甲乙丙丁庚辛壬癸，戊己居中不用）、地支十二字与八卦四维（乾巽坤艮）相配而成，每向十五度，较后世三百六十度分法更合古风。
  - **支点设计**：其一为**顶针式**（旱罗盘），盘心立一铜针或尖柱，磁针中腰套一凹底帽（或嵌玛瑙），针以帽顶立于轴上，四周以角质或铜制边框护持；其二为**浮针式**（水罗盘），针系于浮体置入盛水之盘，中设孔以定位，船行颠簸亦不倾倒。
  - **罗盘装配**：针体与盘面刻度经校准后，固定于木匣或漆盒内，盒面罩玻璃或云母以避风、防尘，遂成航海与堪舆通用之"罗经"。
- **误差认知**：沈括记磁针"常微偏东，不全南也"——即磁针并非正指南北，而略偏于地理南北方向。这是世界科学史上对**磁偏角**的最早明确记载，比欧洲的同类发现早约四百年。

## 🌍 应用与传播

- **北宋航海**：朱彧《萍洲可谈》载"舟师识地理，夜则观星，昼则观日，阴晦观指南针"——阴雨天以罗盘定向，为当时世界上最先进的航海导航手段。
- **南宋远航**：商船配罗盘远航印度洋、阿拉伯，泉州等港口的船队借此深入南洋与波斯湾，海上贸易空前繁盛。
- **西传欧洲**：罗盘经阿拉伯商人传入欧洲，启发了地磁定向与全天候航行；随之而来的地理大发现、哥伦布横渡大西洋与麦哲伦环球航行，皆赖罗盘定其航向。
- **划时代意义**：人类导航从"星象导航"跃升为"全天候定向"，海陆交通从此不再受阴晦天气与白昼黑夜的束缚，世界自此连成一片。
