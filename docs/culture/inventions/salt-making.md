# 🧂 盐的提取

> 人无盐则无力，国无盐则不立。古人尊盐为"百味之王"——饭可无肉，菜不可无盐；千里行军，一担盐胜过一担金。管仲以盐铁富齐，汉武帝因盐铁强汉，一部制盐史，半部是王朝的财政账本。从海边的灰堆到自贡的天车，一根卤脉，牵动着整个文明的命脉。

---

## 📖 盐与人类生存

- **盐是身体的"定盘星"**：食盐供给人体必需的钠离子与氯离子，维持渗透压平衡与神经传导。汗流得多了、盐排得多了，人便四肢无力、头晕眼花——古话说"无盐则无力"，劳作者不补盐，再壮的汉子也撑不过一个农忙。
- **盐铁专卖为何重要**：人人都要吃盐、天天都要吃盐，盐的需求不会因年成而波动。管仲相齐首创"官山海"，盐铁归官营，富国而不扰民；汉武帝时桑弘羊推行盐铁官营，国库得以支撑连年征伐。盐，是古代国家最稳定的一笔"战略税收"。
- **中国四大盐源**：沿海煮晒得**海盐**（两淮、长芦、浙闽），山西运城有**池盐**（河东盐池），四川自贡凿井得**井盐**，西北西北内陆有**岩盐**与**湖盐**（青海茶卡、宁夏吉兰泰）——地形决定盐法，靠海煮海、靠井凿井、靠池晒池。
- **盐业的经济地位**：古人把盐税称作"最善之税"，因其分散、隐形、无法逃漏。吴王濞"煮海为盐"富甲一方，自贡盐商筑起"盐都"，一部地方经济史，常常就是一部盐业兴衰史。

## 🌊 方法一：海盐（煮海为盐 / 晒盐）

> 海就在海边，但海水不能直接喝——含盐约 3%，直接下锅煮，一锅水熬干也只得薄薄一层盐。古人的智慧在于：先把盐分"榨"出来，再花柴火。

### 淋卤法（煮海为盐，古代主法）

- **原理**：海水浓度太低，直接煮费柴惊人。先用草木灰与沙土"吃"住海水里的盐，再把富集了盐分的灰土用水淋洗，得到比海水浓数倍的卤水，再入锅煎熬——柴用得少了，盐却出得多。
- **材料**：草木灰/沙土（海滩盐土）、海水、漏坑与淋桶、铁锅（盘铁、煎盘）、燃料、试卤用的莲子或鸡蛋。
- **步骤**：
  1. **取灰**：刮取海边积盐的草木灰、盐渍沙土堆起——这些灰土本身已吸满盐分，是"天然的盐库"。
  2. **堆淋**：灰土置于漏坑之上，以海水反复浇淋，盐分随水下渗，从坑底流出高浓度卤水；浇淋越透，出卤越浓。
  3. **试卤**：取一枚莲子（或鸡蛋）投入卤水——莲子浮于水面、露头越多，说明卤水越浓；沉底则是淡卤，煮之白费柴火。古人称之为"试卤法"，浓度以莲子能浮起为合格。
  4. **煮盐**：合格卤水入铁锅（煎盘）煎熬，旺火逼出水分，水汽散尽后盐粒析出锅底。
  5. **收盐**：趁热捞出盐粒，摊开沥干，即为"盐霜"；收盐须赶在水分将尽未干之时，迟则盐粒返卤、又苦又湿。
- **要点**：煎盐是连续作业，锅灶多为串联的"熬灶"，前锅预热卤水、后锅煎熬成盐，热力往复利用；柴要干柴旺火，火候以"卤沸不溢"为度——火猛则盐焦黄发苦，火弱则出盐慢而费柴。煮十锅不如浓一锅，功夫全在"淋"字上。

### 晒盐法（明代以后沿海主法）

- **原理**：太阳晒、海风吹，自然蒸发海水——省下了全部柴火。沿海滩涂圈地成田，引潮入田，靠日晒风干把卤水一步一步"晒浓"。
- **材料**：盐田（滩涂筑埂成池）、风车/水车（提卤入池）、刮盐板、耙具。
- **步骤**：
  1. **纳潮**：趁涨潮开启田埂闸口，把海水引进盐田，蓄足一池"源头水"。
  2. **蒸发**：卤水自高而低逐池流过——初级池晒淡、中级池晒浓、高级池成卤，古人称"步步留卤"，一池一池把水分交给太阳。
  3. **结晶**：浓卤引入结晶池，日晒风干至过饱和，盐粒开始在池底析出，水面浮起薄薄一层盐花。
  4. **收盐**：以刮盐板耙集盐粒，堆成盐丘、沥去余卤，晒干装包。
- **要点**：晒盐全靠天——晴多雨少的盐区（两淮、长芦）才是晒盐的好地方，一场急雨能毁掉整池卤。卤水浓度要"浓而不苦"，晒过了头，氯化镁、硫酸镁一并析出，盐就带苦味。晒盐省了柴火，却费了地皮与工夫，故明代以后才大行于沿海。

## ⛰️ 方法二：池盐（河东盐池）

> 中原腹地无海，却有上天赐下的天然卤池——山西运城解池，一池卤水养活半个中原。

- **原理**：解池是内陆盐湖，湖底与周围地层含盐，湖水天然成卤——不需要煮、不需要淋，引卤入畦，靠太阳晒出盐来。
- **材料**：解池卤水、畦田（人工筑埂分隔的结晶池）、引水渠、刮盐工具。
- **步骤**：
  1. **垦畦**：在盐池周边筑埂修畦，畦底压实、田埂起坡，形成一格格浅池。
  2. **引卤浇晒**：把池中卤水引入畦内，摊薄摊匀，让日光与风直接作用于水面。
  3. **结晶**：卤水渐浓渐干，盐晶在畦底析出——春夏之交日晒足、水分快，是出盐旺季。
  4. **捞盐**：人工赤足下畦，用刮板把盐层刮拢、耙出、堆垛沥卤；解池盐色白味正，人称"大盐"，历代列为贡品。
- **要点**：解池冬季卤水遇冷会先析出芒硝，须趁春夏气温升高、芒硝溶解度增大时晒制，才能得纯食盐——捞盐也有讲究，雨天不捞，卤水返稀白晒一季。解池地处中原咽喉，历代设"盐池使"专管，盐利直达朝廷。

## 🕳️ 方法三：井盐（四川自贡）

> 四川不靠海、不临池，但地下埋着厚厚的卤水层。中原人煮海，蜀人凿地——向地心讨盐。

- **原理**：自贡一带地下数百米储有天然卤水与岩盐层，凿井穿通含水层，卤水自然上涌或汲提出井，再煮卤成盐。缺了太阳与海，就用人力和火来凑。
- **材料**：盐井（卓筒井）、天车（竹木井架）、牛皮囊/竹筒（汲卤器）、竹笕（输卤管道）、铁锅（灶房）、燃料——自贡还出天然气（火井），正好烧卤制盐。
- **步骤**：
  1. **凿井**：宋人发明"卓筒井"——以竹筒为套管、铁锉为钻头，冲击式钻凿，井深可达数百米；井壁用竹筒护住，防坍塌、隔淡水。凿一口好井，往往要数年功夫。
  2. **汲卤**：井架（天车）之上架绞盘，系牛皮囊或竹筒下井取卤，人畜协力绞提——卤水出井，浓淡以石蕊试之，淡了弃、浓了留。
  3. **输卤**：竹笕（打通竹节、接口糊浆的竹管道）依山就势铺设，把卤水从井口一路送进灶房卤池——百里输卤，一根竹管走遍山沟，这是古代最朴素却最实用的"管道工程"。
  4. **煮卤**：卤水入铁锅煎熬，如煮海法一般试卤、下盐、收盐；自贡"火井"涌出天然气，直接引火煎盐——地下冒出的火，替蜀人烧了几百年的盐锅。
- **要点**：凿井深、汲卤重、输卤远，井盐业成本高，却成就了最发达的生产组织——自贡盐场井灶相望、盐商云集，官府设"盐井司"抽税，盐工、灶户、商帮形成完整产业链。井盐是四种盐法中唯一"人为可控"的——不靠海、不靠天、不靠湖，靠的是钻到地心的那股狠劲。

## 🪨 方法四：岩盐 / 湖盐（西北）

> 西北内陆干旱少雨，却埋着大自然亿万年前存下的盐——岩石里的盐要凿，湖面上的盐直接捞。

- **原理**：**岩盐**是古代海湾干涸后埋入地下的盐层，成岩石状；**湖盐**则是内陆咸水湖在强蒸发下天然结晶的盐。二者都是"现成的盐"，省去大半煮晒工序。
- **材料**：凿子/锤（采岩盐）、粉碎碾、清水（溶盐）、滤布、铁锅或晒场、刮板（捞湖盐）。
- **步骤（岩盐）**：
  1. **凿取**：循盐矿层走向开凿，采出岩盐矿石。
  2. **粉碎溶解**：矿石砸碎、入清水溶解，得饱和卤水。
  3. **过滤**：卤水以滤布/草木灰层滤去泥砂石膏，澄清待用。
  4. **重结晶**：卤水再煮或再晒，析出纯净食盐。
- **步骤（湖盐）**：
  1. **捞取**：湖面结晶的盐层厚实如冰，直接用刮板捞起。
  2. **刮层**：刮去表层风沙浮尘，下层盐粒直接可用。
  3. **摊晒**：摊于湖边晒场略晾，去除残余水分即可装运。
- **要点**：岩盐多夹石膏、芒硝等杂质，生嚼发苦，**必须溶滤提纯**方能入口；湖盐结晶纯度高，几乎无需加工，青海茶卡盐湖的盐"捞起来就是盐"，宁夏吉兰泰盐湖更是自古供给西北的盐库。西北盐利，是茶马互市上最硬的通货。

## 🗺️ 四法速查：该走哪条路

> 落地先看地形——靠海走淋卤，有湖走晒卤，遇盐池引畦，内陆无海无池则凿井。对照下表，照着工序即可开工。

| 盐源 | 典型产地 | 核心工序 | 优点 | 难点 |
|------|----------|----------|------|------|
| 海盐（淋卤法） | 两淮、浙闽沿海 | 取灰 → 堆淋 → 试卤 → 煮盐 | 原料取之不尽，门槛最低 | 极费柴，一场雨毁一锅 |
| 海盐（晒盐法） | 两淮、长芦 | 纳潮 → 蒸发 → 结晶 → 收盐 | 不费柴，成盐量大 | 全凭天气，需大片滩涂 |
| 池盐 | 山西运城解池 | 垦畦 → 引卤浇晒 → 捞盐 | 天然浓卤，工序最省 | 季节性强，须防芒硝 |
| 井盐 | 四川自贡 | 凿井 → 汲卤 → 输卤 → 煮卤 | 不靠天不靠海，产量可控 | 凿井数年，前期投入惊人 |
| 岩盐 / 湖盐 | 青海茶卡、宁夏吉兰泰 | 凿采或捞取 → 溶滤 / 摊晒 | 现成之盐，几乎不费工 | 岩盐须提纯，产地偏远难运 |

## 🧹 盐的提纯与杂质处理

- **粗盐里的三样杂质**：泥沙（混于结晶过程）、石膏（岩盐夹杂）、苦味盐（氯化镁、硫酸镁——含量越高，盐越苦、越易返潮）。
- **提纯三步**：
  1. **溶滤**：粗盐入清水溶解，泥沙石膏沉底，只取上层清卤。
  2. **澄清**：卤中加石膏或草木灰，令悬浮杂质凝聚下沉，静置取清。
  3. **重结晶**：清卤再煮再晒，析出的盐晶洁白无苦味——杂质留在母液里，盐"洗"过一遭，才配入口。
- **"苦卤"的处置**：母液（苦卤）中氯化镁、硫酸镁浓度高，析盐时须趁结晶前弃去余液——卤未尽、苦已随，古人深谙此理，故"收盐必断卤"。
- **品级分级**：古代按盐粒粗细分**大盐**（粗粒，煮盐）、**小盐**（细粒）、**末盐**（粉状，多作腌渍），《天工开物》等古籍详记各地产盐品质——贡盐必选洁白干燥之品，次盐充军需民用，等级分明。

## 📜 历史小考

- **宿沙氏煮海为盐**：传说黄帝时代"宿沙氏始煮海水为盐"（《世本》），是古籍中最早的制盐记载——煮海为盐的历史，至少从上古就开始。
- **《周礼》"盐人"**：周代设"盐人"之官掌盐政，"掌盐之政令，以共百事之盐"，祭祀、宾客、膳羞用盐各有等次——盐官出现在三千年前的职官表上。
- **管仲"官山海"**：春秋齐相管仲首创盐铁官营，以盐利富齐，"民煮海水、官收而鬻之"——专卖之制自此始。
- **汉武帝盐铁官营**：桑弘羊推盐铁官营，设盐官遍天下；昭帝始元六年（前 81 年），朝廷召集贤良文学辩论盐铁之政，桓宽记录为《盐铁论》——一部影响两千年的财经大辩论。
- **卓筒井的荣光**：宋代四川"卓筒井"深井钻凿技术，被李约瑟在《中国科学技术史》中誉为古代深井钻探的骄傲，被认为是近代石油钻井技术的先声。
- **盐税即国本**：从汉代的盐官、唐代的盐法、宋代的盐钞到明清的盐引，盐税长期是古代国家财政的核心支柱——"天下之赋，盐利居半"，非虚言也。
