# 💥 火药

> 从丹房炉火到战场惊雷，一份配方、一套工艺，改写了人类战争与历史的进程。

---

## 📖 发明背景与起源

- **炼丹术背景**：自汉代起，方士为求长生不死之药而设炉炼丹，在反复的丹房实验中偶然发现硫磺、硝石、木炭混合点燃会剧烈爆燃——火药由此在追求升仙的炉火旁萌芽。丹家炼"硝石"时丹炉常"起火""发火"，对易燃易爆之性早有领教。
- **唐代"伏火法"**：炼丹家为驯服这些易爆原料，总结出"伏火"预燃处理技术。唐代清虚子《铅汞甲庚至宝集成》记载了"伏硫磺法""伏硝石法"等，用炭、油等物预先烧燎硫磺、硝石，使其燃性可控。
  - 所谓"伏火"，本是为防止丹炉爆炸而摸索出的防爆经验，却无意间积累了火药配制的关键技术数据。
- **唐末用于战阵**：据《九国志》记载，唐哀帝时郑璠攻豫章，曾以"发机飞火"烧毁城门，火药自此走出丹房、进入战场。
- **火药三要素**：三大组分各司其职——
  - **硝石**（硝酸钾）：氧化剂，受热分解释放氧气，是火药燃烧的"氧库"；
  - **硫磺**：易燃、燃点低，起助燃传火作用；
  - **木炭**：燃料，提供主要燃烧物。
  - 三者齐备，可燃物、助燃物、氧化剂集于一体，一经引燃即剧烈反应。

## ⚒️ 详细制造过程

火药配制分"提纯—配比—研磨—造粒"四步，每一步都有严格的火候与防爆讲究。

- **原料提纯**：
  - **硝石提纯（"煎硝"法）**：粗硝石溶于热水，滤去泥沙杂质，再加热熬煎、静置冷却，使硝石重新结晶析出；如此反复重结晶，可得较纯的硝酸钾。
  - **硫磺提纯（升华法）**：加热硫磺使其升华成蒸气，再冷却凝华结晶，与灰渣分离，得纯净硫磺。
  - **木炭制备（干馏法）**：木材于密闭窑中隔绝空气烧制而成。不同木料炭质有别，**柳木炭**因灰分少、质轻而脆、发火性好而最佳，次为杉木、竹炭等。
- **配方演进**（关键）：
  - 《武经总要》（北宋·曾公亮等，1044 年）载有三种火药配方，是中国现存最早的定量火药配方——
    - **火球火药法**：硝石一斤、硫磺四两，掺松脂、黄蜡、麻茹等辅料，硝硫之比约 **4:1**，以燃烧纵火为主；
    - **蒺藜火球火药法**：配方近似火球，另掺铁蒺藜碎块，燃放时以铁刺杀伤人马；
    - **火炮火药法**：晋州硫磺十四两、窝黄七两、焰硝（硝石）二斤半，另加麻茹、干漆、砒黄、定粉、竹茹、黄丹、黄蜡、清油、桐油、松脂等，其中**硝与硫约为 40:21（近 2:1）**，硝石已占主导，是当时爆燃性最强的配方。
  - 后世逐步优化，定型为现代黑火药的经典配比：**硝石约 75%、硫磺约 10%、木炭约 15%**——硝石恰好提供足量氧将炭、硫烧尽，能量释放最充分、爆速最高。
- **研磨混合**：
  - 硝、硫、炭须**分别研磨**成极细粉末，各过细罗筛以控制粉粒细度；
  - **严禁同臼共研**：硫磺与硝石同碾摩擦易生热起火，故匠规强调"碾硝不与磺同臼"；
  - 按配比称量后，以木杵在木臼中轻捣混匀，或加少量水湿润搅拌，避免干粉飞扬、摩擦生热引发爆燃。
- **造粒**：
  - 混合药粉加适量水（或酒、醋）揉和，经筛网挤压成均匀颗粒，再阴干；
  - **颗粒药**比粉药燃烧面小、燃速可控、性质稳定，便于装填火器与长期储存，现代黑火药仍沿用此工艺；**粉药**则燃速快而不匀，多用于引线、信号等场合。

## 🔫 军事应用

- **北宋火器**：火球、蒺藜火球、铁嘴火鹞、竹火鹞等燃烧类火器，以及"火药箭"（箭杆缚药筒、点火发射）、震天雷（铁壳装药、炸裂伤敌）、霹雳炮等爆炸类火器相继登场。
- **《武经总要》**：北宋官方军事百科全书，不仅载有火药配方，还详记多种火器的制造与使用之法，是研究早期火药的里程碑文献。
- **金、元发展**：金军攻城中曾以"震天雷"炸城破敌；南宋绍兴二年（1132 年）陈规守德安创"火枪"，开庆元年（1259 年）寿春府造**突火枪**——以巨竹为筒、内实火药并"子窠"（弹丸），已是管状火器（火枪）的雏形；元代至顺三年（1332 年）铸成的铜火铳，为现存最早有纪年的金属管状火器。
- **战争形态改变**：火药武器使城墙、重甲、骑兵阵列的威力相对下降，攻坚与远程杀伤力大增，战争由近身搏杀向远程火器对抗演进，冷兵器时代由此走向终结。

## 🌍 传播与影响

- **西传之路**：十三世纪蒙古西征，将火器与火药配方带入中亚、西亚，复经阿拉伯商人、学者之手传入欧洲；阿拉伯文献中称硝石为"中国雪""中国盐"，正是其东来印记。
- **欧洲变革**：十四世纪起火炮与枪械在欧洲普及，哥特式城堡的城墙在炮火下土崩瓦解，攻防体系被迫重建，骑士重甲亦为火器所克，战争与社会结构随之重塑。
- **历史评价**：恩格斯在《自然辩证法》中写道，火药把**骑士阶层炸得粉碎**——它与印刷术、指南针一同，被列为预告欧洲资产阶级社会到来的三大发明，成为欧洲近代社会变革的重要技术前提。
