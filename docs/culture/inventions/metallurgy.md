# ⚒ 炼铁炼钢

> 青铜礼器铸造了王权，而铁器改写了人间。当铁犁划开战国时代的土地，铁剑劈开秦汉的战场，一种比青铜更便宜、更强韧的金属悄悄取代了它的前辈——中国人在两千多年前完成了这场"金属革命"。若你穿越回战国时期的高炉前，看懂炉火里的化学反应，就能从一堆石头中炼出改变历史的第一块铁。

---

## 📖 冶铁技术的起源

- **陨铁与矿石冶铁是两回事**：陨铁是天上掉下来的天然铁镍合金，古人捡到即可锤打成器（商代铁刃铜钺即以陨铁所制），无须冶炼；而矿石冶铁，是人类**第一次主动从矿石中"炼"出金属**——用火与化学手段，把铁从氧化铁里夺回来。这才是冶铁技术真正的起点。
- **中国的冶铁起步**：春秋晚期（约前 6 世纪）出现**块炼铁**的萌芽；战国时期（前 5—前 3 世纪）**生铁冶铸**成熟，并发明铸铁与柔化处理，比欧洲（14 世纪才出现生铁冶炼）**早约一千五百年**。
- **铁为何取代青铜**：青铜（铜锡合金）铸器精良，但铜矿稀少、锡矿更贵；铁矿则遍地皆是，且铁强度更高、硬度更大、成本更低。铁的普及不是某一次发明，而是资源、性能、成本三重优势的必然结果。

## 🏭 生铁冶炼（高炉冶铁）

> 生铁冶炼是冶铁史的分水岭：炉温越过铁矿石的还原门槛，铁以液态流出，浇铸成任意形状——这是块炼法永远做不到的。中国古代高炉是**竖炉**，基本原理一脉相承地延续了两千多年。

### 原理

- 木炭既是燃料又是**还原剂**：燃烧生成一氧化碳（CO），把铁矿石中的氧化铁（Fe₂O₃ / Fe₃O₄）还原为金属铁。
- 铁矿石熔点约 1500℃，但还原出的铁在高温下**吸收木炭中的碳**，含碳升高后熔点骤降至 1150℃ 上下——于是铁**熔化**成液态，从炉底流出，成为**生铁**。
- 石灰石入炉高温分解为氧化钙，与矿石中的脉石（杂质）结合成**低熔点炉渣**，浮于铁液之上，实现"铁渣分离"。

### 材料

- **铁矿石**：磁铁矿（Fe₃O₄，最富）、赤铁矿（Fe₂O₃，最普遍）、褐铁矿（含水氧化铁，易采易炼）。
- **木炭**：燃料兼还原剂，古代唯一可靠的还原手段。高炉吃炭量极大，"一炉铁，十里林"并非虚言。
- **石灰石**：造渣剂，与脉石化渣，护炉又护铁。

### 步骤

1. **筑炉**：竖炉以夯土或石砌外壁，内衬**耐火泥**，炉腹略鼓（利于气流上升与物料停留），炉顶开口装料，近炉底开出**铁口与出渣口**，炉侧设鼓风风口。
2. **装料**：铁矿石、木炭、石灰石按比例**分层**从炉顶填入——一层矿、一层炭，如垒千层饼。
3. **鼓风**：以皮囊（橐）或风箱向炉内鼓风，炉温升至 **1200℃ 以上**，保证还原与熔化同时进行。
4. **还原**：炉内木炭不完全燃烧生成 CO，CO 沿炉身上升途中把氧化铁逐级还原为铁；铁水渗碳后聚于炉缸。
5. **排渣**：石灰石化渣后浮于铁水之上，从高处的渣口先排出；渣尽后再开低处出铁口。
6. **出铁**：打开炉底出铁口，**生铁水**流入砂型或陶范，浇铸为犁铧、铁锭，或直接铸成器物。

### 要点

- **成败全看温度与风量**：炉温不足则还原不完全，铁水凝不成流；鼓风一停，炉温即坠。
- **皮囊换风箱，人力换水力**：战国西汉用**人力皮囊**（数人轮流踩动"橐"），风小且费工；**东汉初杜诗任南阳太守，"造作水排，铸为农器"**（《后汉书·杜诗传》）——以水轮驱动鼓风机，**水力鼓风**大大提升炉温与产量，后世历代沿用，"一水之功，可敌十夫"。

## 🧱 铸铁与柔化处理

### 生铁为何硬脆

- 生铁含碳量**高达 3% 以上**，碳以**渗碳体（Fe₃C）**形式大量析出，硬如瓷而脆如玻璃，一锤即碎、不能锻打，只宜浇铸——所以生铁又叫"铸铁"，能铸不能锻。

### 柔化处理（可锻铸铁）

- **原理**：把铸铁件埋在炭粉或铁矿石粉中**密封加热、长时间保温、缓慢冷却**（退火）。高温下外层渗碳体**脱碳**成铁，内层渗碳体**石墨化**析出石墨，于是硬脆的生铁变成**可锻铸铁**——能锻、能弯、不易断。
- **步骤**：铸件 → 入箱埋炭密封 → 加热至红热保温数日 → 缓缓冷却 → 出箱去灰。火候与保温时间是关键：时间不足则脱碳不匀，火候过头则晶粒粗大。
- **战国时已成熟**：河北易县燕下都出土的战国铁农具、铁兵器，大量为柔化处理的可锻铸铁，说明此工艺在战国已广泛普及。
- **要点**：柔化处理是"让生铁从不能锻变成可用"的关键一步，它与后文的**炒钢**共同构成从生铁到工具的两条出路——一条做铸铁农具，一条炼钢打铁。

## ⚡ 炼钢工艺（核心章节）

> 铁贵在"炼"成钢。钢是含碳量适中（0.02%—2.1%）的铁碳合金：含碳低则软（熟铁），含碳高则脆（生铁），恰到好处才刚柔并济。中国古代走通了**从两端向中间凑**的炼钢路线——要么给熟铁"加碳"（渗碳），要么给生铁"减碳"（脱碳）。

### 块炼铁渗碳钢（加碳路线·最早的钢）

- **原理**：块炼铁（海绵状熟铁，含碳极低、质软）在 **800—1000℃** 的木炭火中反复加热，碳自表面向内部**渗入**，表层变成含碳合适的钢。
- **步骤**：炼出海绵铁 → 反复锻打挤渣 → 入炭火加热渗碳 → 再锻打使碳均匀 → 如此"加热—锻打"多轮。
- **要点**：春秋战国之交已能生产，但工序繁、产量低、质量不均，只够打兵器，满足不了农具的大规模需求。

### 炒钢法（减碳路线·汉代突破）

- **原理**：生铁加热至半熔状态，用木棍或铁棍在炉中**反复搅拌**（形如"炒菜"——故称"炒钢"），让空气中的氧把碳**氧化脱除**；搅到什么程度停手，就得到什么含碳量的钢或熟铁。
- **步骤**：生铁入炒钢炉 → 猛烈鼓风加热至半熔 → 不停搅拌，铁水渐稠成"铁坨" → 取出趁热锻打成材。
- **要点**：汉代普及，河南巩义铁生沟汉代冶铁遗址即用此法；产量高、成本低，一下把"钢"从贵族兵器变成了百姓农具。**缺点是含碳量全凭经验目测**，质量难稳定。

### 灌钢法（南北朝·綦毋怀文，当时世界最先进）

- **原理**：以**生铁水浇灌熟铁**——生铁含碳高、熔点低，熔化的铁水浇在熟铁条上，碳便向熟铁**渗入**，两相搅合，得到成分均匀的钢。这是把"加碳"与"减碳"揉成一体的复合路线。
- **步骤**：熟铁条盘卷成束入炉 → 生铁块置于其上 → 鼓风熔化生铁 → 铁水淋灌熟铁并反复搅合 → 取出折叠锻打均匀 → 成钢。
- **名匠綦毋怀文**：《北齐书》载他"**烧生铁精以重柔铤，数宿则成钢**"；又造"**宿铁刀**"，"以柔铁为刀脊，浴以五牲之溺，淬以五牲之脂"，"斩甲过三十札"。
- **要点**：省料、省工、质量稳定，兼得生铁的高产与熟铁的韧性，自南北朝起一直用到明代，《天工开物》仍详载此法。

### 百炼钢（锻打路线）

- **原理**：把钢坯**反复折叠、锻打、再折叠**，每一次锻打都挤出夹杂、均匀成分、细化晶粒，钢质愈发致密坚韧。
- **要点**："百炼"是形容反复锻打次数之多，"**百炼成钢**"一词即由此而来；汉代"三十炼""五十炼""百炼"刀剑铭文屡见，多用于宝刀宝剑。

### 淬火与回火（热处理·最后的点睛）

- **原理**：钢烧红后**急速冷却**（淬火），晶格被"锁死"，钢变得**极硬**；但淬火后脆性大增，需再**低温回火**（缓慢再加热）消除内应力，刚柔方得兼备。
- **介质讲究**：**水淬**最硬最脆，**油淬**较柔韧；綦毋怀文更以牲畜尿（五牲之溺）与动物脂（五牲之脂）分别淬刃口与刀脊——刃口要硬，刀脊要韧。
- **要点**：淬火火候差之毫厘、失之千里——过烧则崩口，欠淬则发软。同炉出钢，介质不同、部位不同，兵器性能便天差地别。

## 🔪 铁器应用与影响

- **铁农具推动农业革命**：战国铁犁、铁锄、铁镰取代木石农具，配合牛耕，实现深耕与大规模开荒——粮食增产是人口增长、城市兴起的物质基础。
- **铁兵器改写战争形态**：铁剑、铁甲、铁枪头全面列装，秦汉军队的战斗力，一半在阵法，一半在钢铁。
- **工艺体系影响深远**：炒钢、灌钢、淬火这套"生铁—炒炼—灌铸—热处理"的完整体系，从汉代一直延续到明清，《天工开物》记载的"灌钢"操作与南北朝一脉相承。
- **长期领先世界**：生铁冶铸比欧洲早约一千五百年；百炼钢、灌钢在唐代传入朝鲜、日本，深刻影响了东亚冶金进程。
