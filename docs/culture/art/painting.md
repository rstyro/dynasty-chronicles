# 🖼 绘画

> 外师造化，中得心源。

---

中国绘画以笔墨为骨、意境为魂，人物、山水、花鸟三科并立。从六朝传神到宋元写意，画家在咫尺画幅中寄托胸中丘壑。

## 魏晋六朝：传神论的诞生

- **顾恺之**（东晋）：提出"以形写神"，传世摹本《女史箴图》《洛神赋图》笔意连绵，人物顾盼有情。
- **谢赫六法**（南齐）：《古画品录》立"气韵生动"为首，成为中国画论千年圭臬。
- **敦煌壁画**：北朝洞窟中飞天伎乐、本生故事，西域画风与中原传统初融。

## 隋唐：工笔重彩的黄金时代

| 画家 | 代表作品 | 成就 |
|------|----------|------|
| 展子虔 | 《游春图》 | 现存最早山水卷轴 |
| 阎立本 | 《步辇图》 | 初唐纪实人物画 |
| 吴道子 | 《送子天王图》 | "画圣"，吴带当风 |
| 周昉 | 《簪花仕女图》 | 雍容华贵的仕女画 |
| 王维 | 诗画一体 | "诗中有画，画中有诗" |

唐代分科专精：人物、鞍马、山水并盛，青绿与水墨双轨并行，吴道子"笔不周而意周"，开写意先声。

## 五代两宋：山水人物双峰并峙

- **荆浩、关仝、董源、巨然**：南北山水并立，皴法渐成，奠定水墨山水法则。
- **顾闳中**：《韩熙载夜宴图》夜宴长卷，人物神态毕肖，五代人物画巅峰。
- **范宽**：《溪山行旅图》雄峻浑厚，北宋全景式山水之冠。
- **张择端**：《清明上河图》五米长卷，汴京市井百业尽收，风俗画的百科全书。
- **徽宗赵佶**：设翰林图画院，"宣和画谱"、瘦金体与工笔花鸟并称。

## 宋元文人画：以意写之

- **苏轼**：首倡"士人画"，"论画以形似，见与儿童邻"。
- **米氏云山**：米芾、米友仁父子以墨点晕染烟雨江南。
- **黄公望**：《富春山居图》披麻皴写富春江之胜，被誉为"画中兰亭"，为元四家之首。
- **倪瓒**：一水两岸、空亭枯树，简淡孤高，逸笔草草。

## 明清：流派纷呈与四僧

- **沈周、文徵明、唐寅、仇英**：吴门画派，文人雅集蔚然成风。
- **徐渭**：大写意泼墨花卉，狂放淋漓。
- **八大山人**（朱耷）：白眼向天的鱼鸟、残山剩水，冷逸奇崛，遗民孤愤尽付笔端。
- **石涛**："搜尽奇峰打草稿"，主张"笔墨当随时代"。
