# 🏛 建筑与园林

> 建筑是凝固的音乐，园林是立体的诗画。

---

中国建筑以木构为骨、庭院为魂，礼制与自然并重。皇家宫阙气象森严，文人园林则把山水请进家中，一石一水皆含宇宙。

## 木构体系与中国建筑

- **木结构**：以柱、梁、斗栱承重，墙体只作围护，"墙倒屋不塌"。
- **斗栱**：檐下层层出跳的承托构件，既是结构也是装饰，唐代雄大、明清繁密。
- **院落布局**：中轴对称、纵深递进，体现宗法礼制的空间秩序。
- **琉璃与彩画**：屋顶、墙面以琉璃与彩绘点染，等级森严而色彩辉煌。

## 故宫：帝王之家的秩序

- **明清皇宫**：紫禁城南北长九百余米，宫殿九千余间，为世界现存最大木构建筑群。
- **中轴对称**：午门、太和殿、乾清宫一线贯通，"前朝后寝，左祖右社"。
- **太和殿**：重檐庑殿顶，金銮宝座居天下之正，为礼制建筑的极则。
- **色彩礼制**：黄琉璃瓦专属皇家，屋顶吻兽数目彰显等级。

## 天坛：礼制建筑的巅峰

- **祈年殿**：三重檐攒尖圆顶，蓝色琉璃瓦象征苍天，以圆象天、以天承命。
- **圜丘坛**：三层白石坛，天心石立于中央，人声在台心回响，恰如"天人感应"。
- **祭天礼乐**：冬至祭天、祈谷求年，建筑与礼乐、历法合为一体。

## 苏州园林：移步换景的文人意境

| 名园 | 特色 |
|------|------|
| 拙政园 | 以水为主，疏朗明洁，明四家文徵明曾参与经营 |
| 留园 | 建筑精巧，冠云峰太湖石瘦漏透皱 |
| 网师园 | 小园极致，亭榭廊庑收放自如 |
| 狮子林 | 假山迷宫，叠山理水奇绝 |

- **造园手法**：借景、对景、障景，曲径通幽，咫尺山林。
- **文人园林精神**：归隐山林的诗意栖居，"虽由人作，宛自天开"。

## 皇家园林：颐和园

- **颐和园**：清漪园被英法联军焚毁后于光绪年间重建，以万寿山、昆明湖为骨架。
- **借景西山**：远借玉泉山塔影，湖山一体，为"三山五园"最后绝唱。
- **长廊**：东起邀月门，西至石丈亭，七百余米彩画长廊，汇山水、历史、传说于一体。
- **佛香阁与十七孔桥**：万寿山中轴收束全园，十七孔桥卧波如虹。
