# 💎 篆刻与玉器

> 石可言志，玉可载德。

---

篆刻与玉器，一为刀笔方寸之艺，一为琢磨温润之器，皆以"切磋琢磨"成其美。玺印自先秦官私之凭，至明清而蔚为文人艺术；玉器自新石器通神之器，至清乾隆而登峰造极。

## 篆刻：从玺印到文人艺术

### 秦汉玺印之源

- **先秦古玺**：大小悬殊、朱白不一，文字奇肆古朴，六国文字并存，开玺印艺术之先河。
- **秦印**：凿刻"田"字界格，小篆入印，规整中见灵动，"秦玺汉印"并称后世典范。
- **汉印**：缪篆平正端庄，官印私印体系完备，后人学印多从汉印入手，谓"宗法秦汉"。

### 文人篆刻的兴起

- **吾丘衍**（元）：著《学古编·三十五举》，首倡以汉篆入印，为文人篆刻理论奠基。
- **文彭**（明）：以灯光冻石刻印，引石章入文房，被尊为文人篆刻开山之祖。
- **何震**（明）：继文彭而起，"文何"并称，单刀刻款，猛利爽健，开创雪渔派。

### 明清流派纷呈

| 流派 | 代表印人 | 风格 |
|------|----------|------|
| 皖派 | 邓石如 | "印从书出"，以书入印，圆劲婀娜 |
| 浙派 | 西泠八家 | 丁敬为首，切刀碎切，苍茫古朴 |
| 融会派 | 赵之谦 | 印外求印，取资泉布碑版，面目一新 |
| 海派 | 吴昌硕 | 雄浑苍劲，钝刀硬入，金石气盛 |
| 齐白石 | 齐白石 | 单刀直冲，红白对比强烈，"不知有汉" |

- **诗书画印一体**：自赵孟頫、文彭以降，印章成为书画作品不可分割的一部分，"诗书画印"并称文人四艺。

## 玉器：从通神到入世

### 史前玉文化

- **红山文化玉龙**：C 形碧玉龙蜷曲腾跃，有"中华第一龙"之誉，北方玉文化的代表。
- **良渚玉琮**：内圆外方，神人兽面纹细如毫发，玉琮玉璧构成沟通天地的原始信仰体系。

### 商周礼玉

- **妇好墓玉器**（商）：出土玉器 750 余件，玉凤、玉人精雕细琢，商代王室用玉之盛可见一斑。
- **周代玉制**："六器"礼天地四方，"君子比德于玉"，玉由神坛走向道德象征。

### 汉玉之绝唱

- **金缕玉衣**：满城汉墓中山靖王玉衣以金丝缀玉片两千余，事死如事生的殓葬极致。
- **汉八刀**：玉蝉、玉翁仲寥寥数刀而成，刀法简练劲健，为汉玉典型工艺。

### 唐宋世俗化与明清鼎盛

- **唐宋玉器**：飞天玉佩、执荷童子等题材入玉，器用化、装饰化，玉器走向世俗生活。
- **乾隆工**：清宫玉作不计工本，琢磨精绝，痕都斯坦玉风亦受推崇。
- **大禹治水图玉山**：重逾五吨，前后雕琢十年，为中国玉器史上最大的作品，乾隆朝玉雕巅峰。
