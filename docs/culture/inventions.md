# 🔬 科技发明

> 四大发明改变世界，天工开物匠心独运。

---

## 四大发明

| 发明 | 时期 | 说明 |
|------|------|------|
| **造纸术** | 西汉（改进于东汉蔡伦） | 取代竹简和帛，推动知识传播 |
| **指南针** | 战国（司南）→ 宋代成熟 | 用于航海，开启大航海时代 |
| **火药** | 唐代 | 军事革命，改变战争形态 |
| **印刷术** | 唐代（雕版）→ 宋代（活字） | 毕昇发明活字印刷，加速文化传播 |
