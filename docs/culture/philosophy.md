# 🧠 思想哲学

> 百家争鸣，三教合一——塑造中国人精神世界的思想图谱。

---

## 主要思想流派

### 🎋 儒家

- **创始人**：孔子
- **代表人物**：孔子、孟子、荀子、董仲舒、朱熹、王阳明
- **核心理念**：仁、义、礼、智、信；修身齐家治国平天下
- **经典**：《论语》《孟子》《大学》《中庸》（四书五经）
- **演变**：先秦儒学 → 汉代经学 → 宋明理学 → 阳明心学

### 🌿 道家

- **创始人**：老子
- **代表人物**：老子、庄子
- **核心理念**：道法自然、无为而治
- **经典**：《道德经》《庄子》

### ⚖️ 法家

- **代表人物**：商鞅、韩非、李斯
- **核心理念**：以法治国、严刑峻法、富国强兵
- **影响**：秦朝治国思想基础

### 🤝 墨家

- **创始人**：墨子
- **核心理念**：兼爱、非攻、尚贤、节用
