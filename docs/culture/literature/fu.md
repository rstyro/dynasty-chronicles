# 🐉 赋

> 赋者，"铺采摛文，体物写志"，介于诗文之间，两汉文章之宗，亦中国文学中最恢弘的体裁。

---

## 内容（按时期或类别组织）

### 先秦：赋之滥觞

- **荀子《赋篇》**：最早以"赋"名篇之作，咏礼、知、云、蚕、箴五物，遁词隐意、问答成篇，"赋"之名实由此确立。
- **宋玉**：屈原之后楚辞名家，《风赋》托风以讽谏襄王，《高唐》《神女》铺陈云雨迷离之境，由骚体向赋体过渡，汉赋体制实导源于此。

### 汉大赋：包括宇宙、总揽人物

- **司马相如**：《子虚赋》《上林赋》虚构子虚、乌有、亡是公三人问答，铺写游猎苑囿之盛，"劝百讽一"，为汉大赋极则，武帝读之叹"独不与寡人同时"。
- **班固《两都赋》**：东西都宾主夸饰长安、洛阳，开创京都大赋格局，张衡继作《二京赋》"精思傅会，十年乃成"，体制更趋宏丽。
- **张衡《归田赋》**：晚年抒归隐之志，短小清丽，为大赋向抒情小赋转变之先声。

### 魏晋南北朝：抒情小赋与骈赋

- **王粲《登楼赋》**：避乱荆州登楼怀乡，"虽信美而非吾土兮"，去国怀乡之痛千古同慨，建安抒情小赋代表。
- **曹植《洛神赋》**：叙遇洛水女神而人神道殊，"翩若惊鸿，婉若游龙"，辞采华茂，寄寓身世之悲，为曹植"文章曹植波澜阔"的极致。
- **庾信《哀江南赋》**：由南入北，身仕两朝，痛梁朝覆亡，"不无危苦之辞，惟以悲哀为主"，集骈赋之大成，杜甫谓"庾信文章老更成"。

### 唐宋：律赋与文赋

- **唐律赋**：科举试赋，限韵成篇，格律严整而渐伤气骨，为功令文体。
- **杜牧《阿房宫赋》**：借秦警唐，"秦人不暇自哀，而后人哀之"，骈散兼行、气势纵横，晚唐文赋先声。
- **欧阳修《秋声赋》**：写秋声之凄切、人生之易老，骈句与散笔交融，一洗板滞，文赋体制至此成熟。
- **苏轼前后《赤壁赋》**：泛舟赤壁，主客问答，融景、理、情于一炉，"惟江上之清风，与山间之明月"达观超然，文赋之极诣，亦千古绝唱。
