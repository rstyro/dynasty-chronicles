# 📖 文学

> 从"关关雎鸠"到"满纸荒唐言"——中华文学的璀璨星河。

---

## 文学发展脉络

### 先秦

- **《诗经》**：中国第一部诗歌总集，"风雅颂"
- **《楚辞》**：屈原《离骚》，浪漫主义源头
- **诸子散文**：《论语》《孟子》《庄子》《韩非子》

### 两汉

- **汉赋**：司马相如《子虚赋》
- **史传文学**：司马迁《史记》——"史家之绝唱，无韵之离骚"
- **乐府诗**：《孔雀东南飞》《陌上桑》

### 魏晋南北朝

- **建安文学**：曹操、曹丕、曹植
- **田园诗派**：陶渊明
- **志怪小说**：《搜神记》

### 隋唐

- **唐诗巅峰**：李白（诗仙）、杜甫（诗圣）、白居易
- **古文运动**：韩愈、柳宗元
- **传奇小说**：《莺莺传》《李娃传》

### 宋元

- **宋词**：苏轼（豪放）、李清照（婉约）、辛弃疾
- **元曲**：关汉卿《窦娥冤》、马致远《天净沙·秋思》
- **话本小说**：《碾玉观音》

### 明清

- **四大名著**：《三国演义》《水浒传》《西游记》《红楼梦》
- **文言短篇**：《聊斋志异》
- **讽刺小说**：《儒林外史》
