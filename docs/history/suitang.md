# 🥇 隋唐盛世

> 581–907 ｜ 制度成熟、万国来朝，中国中古史的巅峰，也是转折点。

---

## 📖 一条主线

**隋**在 581 年由杨坚建立，589 年灭陈，结束近三百年分裂。隋文帝推行三省六部、科举取士、均田与租庸调，开皇年间国力强盛；隋炀帝修大运河、营洛阳、三征高句丽，过度役使民力，最终引发全国性动乱，618 年隋亡。隋虽短命，却把北朝的制度实验固化下来，直接交给唐朝。

**唐**在 618 年由李渊建立。626 年玄武门之变后，李世民即位，开创"贞观之治"：纳谏、轻徭、完善三省六部与科举，对外击败东突厥，被尊为"天可汗"。高宗、武则天时期疆域进一步扩张；玄宗前期出现"开元盛世"，长安成为当时世界最繁华的都市之一。诗歌、书法、绘画、佛学、乐舞都在此时达到高峰。

**转折**发生在 755 年。安禄山、史思明发动安史之乱，八年战乱使北方经济残破，唐朝由盛转衰。此后藩镇割据、宦官专权、牛李党争轮番消耗中央权威；875 年黄巢起义席卷南北，907 年朱温篡唐，唐朝灭亡，进入五代十国。
