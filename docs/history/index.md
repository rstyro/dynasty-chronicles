# 🧭 历史脉络

> 不要从词条开始，从时间开始。

如果你打开一个朝代页，看完仍不知道"然后呢"；打开一个人物页，不知道他处在历史哪一段——问题不在内容太少，而在缺少一条**时间主线**。

这一栏目就是那条主线：把历史切成 10 个时代，每个时代用一页讲清三件事——

1. **上一期留下了什么**：它继承的局面；
2. **这一期发生了什么**：主线事件、转折与制度变化；
3. **它把什么交给了下一期**：为什么下一时代会长成那个样子。

## 📖 三种读法

### 1. 顺读：第一次了解中国史
从 [上古](/history/ancient) 开始，按"下一期"一路读到 [大一统皇朝](/history/imperial)。每期只记住三件事：**怎么来的、发生了什么、怎么没的**。

### 2. 按朝代读：查一个王朝的前后关系
从 [朝代总览](/dynasties/) 进入具体朝代。每个朝代页顶部都有一条"时代坐标"，标出**上一朝、下一朝、同期政权**，读完可以顺着走，不会断。

### 3. 按主题读：带着问题找答案
先看 [时间线](/timeline) 建立年代感，再按人物、战役、文化三条支线深入。每个时代页底部都给了三组入口。

如果已经读完一轮时代页，可以换到横向视角：[制度演变](/threads/institutions)、[民族融合](/threads/ethnic-fusion)、[经济重心南移](/threads/economy-southward)、[技术传播](/threads/technology)——四条问题线各自跨越多个朝代，专门回答"为什么一次次出现相似局面"。
