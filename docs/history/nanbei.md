# 🤝 南北朝 · 民族融合

> 420–589 ｜ 南北对峙一百七十年，却为下一个大一统准备了制度与人才。

---

## 📖 一条主线

**南朝**从 420 年刘裕代晋建宋开始，历经宋、齐、梁、陈四朝，均都建康。南朝继承东晋的门阀政治，但皇权逐步加强；江南经济持续开发，海外贸易与佛教寺院经济兴盛。梁武帝萧衍在位近五十年，晚年因侯景之乱导致江南残破。陈朝国力最弱，589 年被隋所灭。

**北朝**的起点更早。386 年拓跋珪建立北魏，439 年太武帝统一北方，与南朝形成南北对峙。北魏孝文帝迁都洛阳、改汉姓、穿汉服、说汉语、通婚士族，把"汉化"推向高潮。但改革也激化了六镇军民的不满，最终引发动乱。北魏分裂为东魏、西魏，又演变为北齐、北周。北周在宇文泰、宇文邕经营下推行府兵制、均田制，国力反超北齐；577 年北周灭北齐，北方再次统一。

**南北之间**并非只有战争。使节往来、佛教传播、人口迁徙与边境贸易，让胡汉文化深度交织。南朝的文学、书法、佛学影响北方；北方的制度实验（均田、府兵、户籍）则被隋唐继承。581 年杨坚代周建隋，589 年隋灭陈，中国重新统一。
