# 🏛️ 制度演变

> 从"封邦建国"到"军机处跪受笔录"——每一次制度调整，都是对前一代失控的回应。

---

## 📖 一条主线

中国制度史可以概括为一句话：**皇权不断集中，官僚体系不断专业化**。

但这条线不是直线。封建过度导致诸侯坐大，于是秦改郡县；郡县过刚导致二世而亡，于是汉搞郡国并行；藩镇失控导致唐亡，于是宋把兵权、财权、政权全部收归中央；宰相权力过大让朱元璋不安，于是明太祖干脆废掉丞相。**制度的每一次大改，几乎都能在前朝的崩溃里找到原因。**

---

## 🧱 西周：分封与宗法

周天子把土地和人民分封给同姓宗亲、功臣和先代贵族，形成 **天子—诸侯—卿大夫—士** 的等级秩序；宗法制以嫡长子继承制确定权力传承，礼乐制度则把等级变成日常规范。

这套制度在交通与通讯有限的青铜时代极为有效，但它默认周天子始终强大。一旦王室衰微，诸侯就会从"屏藩"变成"竞争者"——[春秋战国](/history/dongzhou) 的乱世正由此而来。

## 🏯 秦：郡县与皇帝

前 221 年秦统一六国后，做了三件影响两千年的事：

1. **皇帝制度**：君主不再称"王"，而是"始皇帝"，权力高度人格化；
2. **郡县制**：地方长官由中央任免、定期调动，彻底取消世袭封国；
3. **三公九卿**：丞相、太尉、御史大夫分掌行政、军事、监察，形成中央官僚框架。

秦还统一文字、度量衡与车轨，把"统一"从军事事实变成制度事实。但秦以法家治国、徭役过重，二世而亡，说明**只靠强制力无法维持大一统**。

- 相关：[秦朝](/dynasties/qinhan/qin) ｜ [法家与墨家](/culture/philosophy/legalism-mohism)

## 🐉 汉：郡国并行到推恩

汉初吸取秦亡教训，实行 **郡国并行**：中央直辖郡县，同时分封同姓诸侯王。结果前 154 年爆发七国之乱。汉武帝随后推行 **推恩令**，让诸侯国越分越小，再用察举制把选官权收归中央，以"独尊儒术"为官僚体系提供统一的意识形态。

汉武帝还设内朝牵制外朝丞相，开创了此后反复出现的"皇帝用近臣架空正式官僚"的模式。

## ⚖️ 魏晋南北朝：门阀与制度实验

曹魏推行 **九品中正制**，本意是按才能选官，结果被世家大族把持，形成"上品无寒门，下品无势族"的门阀政治。

乱世之中也留下了重要遗产：北魏推行 **均田制** 与 **三长制**，把土地、户籍和基层治理重新组织起来，成为隋唐制度的直接来源；北周的 **府兵制** 则让兵农合一，为隋唐统一提供了军事基础。

- 相关：[十六国](/dynasties/weijin/sixteen-kingdoms) ｜ [北朝](/dynasties/nanbei/beichao)

## 🥇 隋唐：三省六部与科举

隋朝把北朝的制度实验定型为 **三省六部制**：中书省草拟诏令、门下省审议封驳、尚书省下辖六部执行。决策、审核、执行分开，是中国古代官僚制度最成熟的设计之一。

选官制度同步变革：隋炀帝始设进士科，唐代完善 **科举制**，让读书人可以不经门第直接进入官僚体系。经济上，唐前期行均田制与租庸调，780 年改行 **两税法**，按资产和田亩征税，标志着国家财政从"人丁"转向"土地与财富"。

- 相关：[隋朝](/dynasties/suitang/sui) ｜ [唐朝](/dynasties/suitang/tang) ｜ [唐太宗](/figures/emperors/suitang/tang/tang-taizong)

## 🛡️ 宋：分权与制衡

宋太祖吸取唐末藩镇割据的教训，把军权、财权、行政权全面收归中央：**二府三司** 分掌民政军政财政，枢密院掌兵、三司掌财，宰相不再独揽大权；地方设通判牵制知州，财政上收。

"重文抑武"换来内部稳定，却也造成冗官、冗兵、冗费。王安石变法试图以青苗法、募役法、保甲法重整财政与军事，最终在党争中失败。

- 相关：[北宋](/dynasties/songliao/northern-song) ｜ [王安石](/figures/strategists/songliao/beisong/wang-anshi)

## 👑 明清：皇权的顶点

1380 年，朱元璋以胡惟庸案为由 **废除丞相**，六部直接对皇帝负责，中国历史上延续一千六百年的宰相制度终结。永乐以后，皇帝以 **内阁** 协助处理奏章，内阁大学士拥有"票拟"权，但决策权仍牢牢握在皇帝手中。

清代雍正设 **军机处**，军机大臣"跪受笔录"，只承旨办事，不参与决策，皇权集中达到顶峰。经济制度上，明张居正推行 **一条鞭法**、清雍正推行 **摊丁入亩**，赋役逐渐合并、按田亩征收，人身控制进一步松弛。

## 🕐 制度演变时间线

| 时间 | 制度节点 | 影响 |
|:--|:--|:--|
| 西周 | 分封制、宗法制、礼乐 | 确立等级秩序，也埋下诸侯坐大的隐患 |
| 前 221 | 秦建皇帝制、郡县制、三公九卿 | 中央集权国家的基本框架 |
| 前 154 | 汉平七国之乱 | 同姓分封的失败 |
| 前 127 前后 | 推恩令、察举制 | 削弱诸侯，选官权收归中央 |
| 220 | 九品中正制 | 选官制度门阀化 |
| 485 | 北魏均田制、三长制 | 土地与户籍重组，隋唐制度源头 |
| 隋 | 三省六部制定型 | 决策、审议、执行分离 |
| 605 起 | 科举取士 | 打破门第，官僚体系开放 |
| 780 | 两税法 | 从人丁税转向资产税 |
| 宋初 | 二府三司、重文抑武 | 中央集权加强，形成冗官冗兵 |
| 1380 | 明废丞相、设内阁 | 皇权直接面对六部 |
| 1581 | 一条鞭法 | 赋役合并，白银货币化 |
| 雍正 | 军机处、摊丁入亩 | 皇权达到顶峰，人身控制松弛 |
