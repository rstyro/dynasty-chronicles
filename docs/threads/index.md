# 🧵 横向专题

> 朝代是一条时间线，专题是一条问题线。

[历史脉络](/history/) 回答"什么时候发生了什么"；这一栏目回答的是 **"为什么会一次次出现相似的局面"**。

同一个问题，往往要跨好几个朝代才看得清：

| 专题 | 要回答的问题 | 时间跨度 |
|:--|:--|:--|
| [制度演变](/threads/institutions) | 中国如何从分封走向中央集权？皇权为什么越来越集中？ | 西周–清 |
| [民族融合](/threads/ethnic-fusion) | "华夏"的边界如何不断变化？胡汉之间是谁改变了谁？ | 先秦–清 |
| [经济重心南移](/threads/economy-southward) | 中国的钱袋子和粮仓，怎样从北方移到南方？ | 秦汉–清 |
| [技术传播](/threads/technology) | 四大发明为何能改变世界？技术靠什么网络传播？ | 汉–清 |

---

## 🧭 怎么读

1. **先有骨架再读专题**：如果还没读过 [十个时代](/history/)，建议先顺读一遍，否则专题里的人名地名会失去坐标。
2. **带着问题读**：每篇专题开头都给出一个核心问题，正文按"问题—回应—转折"推进，不必逐段背诵。
3. **回到人物和事件**：专题只给线索，细节在具体的人物页、战役页、朝代页里。每篇文末都列了入口。
